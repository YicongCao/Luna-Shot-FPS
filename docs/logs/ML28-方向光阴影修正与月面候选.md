# ML28 — 方向光阴影修正与月面候选

日期：2026-11-18。

## 目标与实际决定

分开处理地面阴影细密斜纹与远景山体折面，不加浓雾、不改暖黄方向，不动场内布局/碰撞。

- 发布方向光软阴影HIGH采样，保留LOW对照；原4096阴影图与太阳角直径不变。
- 制作并验证2.5m网格月面候选，但**不推广为默认**。它虽然减少折面，也削弱山脊/中尺度起伏，不能以几何通过替代视觉收益。

## 排查与纠偏

1. 八组原生阴影隔离证明细密图样与方向光低采样软阴影相关；关闭SSAO/SSIL、SSR或局部阴影不能消除。硬阴影会损失软边，选择HIGH而非禁用阴影。
2. 月面缓存高度、连续法线/切线、限制噪声频谱，29项几何检查通过；仍因“软丘化”的美术损失保留候选。
3. 首轮地形诊断相机受坡面/围界遮挡；提高机位，检查两版表面净空和实际相机姿态。
4. 隐藏Player/WeaponLayer不能隐藏world拥有的独立枪械Bloom。显式关闭诊断合成层后青色残留消失；不改变正常玩法Bloom。
5. 最终两版左右原生背面剔除检查和宽镜头保留。外侧高机位不是玩家可达路线，场景边缘仍可见。

## 边界与经验

原Compatibility训练场、共享环境/ML21枪械、布局/生成器保持，无新Tripo/混元/imagegen调用。程序月面复用旧贴图，不是高模烘焙。7个Texture RID退出警告仍在。

下一轮若继续月面，应保留既有大山形单独修欠采样，而非进一步磨平全部频谱。旧月面棱角、模块重复、非IK步态与整体照片级目标仍开放；用户视觉验收待定。本阶段完成的是阴影修正与一次有边界的候选评估，不是整体3A美术完成。
