# ML22 — 清剿关卡与电影化视觉样板

2026-11-17。用户提出不调用Tripo，以纯代码+imagegen尝试3A照片级、电影宽荧幕光效，增强射击与战斗机HUD，并加入T-Bug清剿、激活终端、撤离的小样。范围从原固定靶训练场扩展为独立任务，不覆盖原训练场默认或ML21资源。

## 交付

`launch-quarantine.command` / `scenes/quarantine.tscn`；`scripts/quarantine` 六个运行脚本和 `assets/quarantine` 四个着色器。8只三发击杀的机械害虫、生命/失败、暂停/重开、清剿门禁、近距离持续E三秒和撤离完成。真实射线伤害仍由既有player.gd/ML13承担，HUD不自动瞄准、不透墙。

程序化上部钢结构/围界/控制台/撤离门框/连续月面，原59个主题实例保留；B11仅在独立场景副本移动到外侧空槽，以消除出生遮挡。新增Forward+入口使用SSAO/SSIL/SSR/TAA、体积尘光、暖主光冷环境与局部灯池，武器独立视口仍使用原安全Bloom合成。激活后能源柱、粒子和扩散环出现。已有imagegen光学素材按真实光源遮挡使用。

新增Tripo 0次，imagegen 0次；本会话未提供imagegen生成工具，没有虚构新素材生成。沿用ML04 streak/halo，新增构造、着色、声音、HUD全部为代码。

## 实机迭代

首轮雾过黄，近景设备过大，HUD细字不足。依据1920×810原生图降低雾、修正色温、移开副本B11，增强HUD最小字号/对比。首轮月面为粗糙分段剪影，改成连续高度场；补顶棚纵梁和檩条，避免悬空板观感；终端降低屏幕过曝，缩小悬浮文字并增加实体铭牌。首轮和中间图均保留，不用后改结果覆盖失败历史。

钢架从逐件Cylinder绘制改为MultiMesh批次；火花固定12槽，不随连射增加节点。枪械高亮仍来自实际独立视口，不为Forward+重新打开会剪透明alpha的原生武器Glow。

## 验证与边界

- 本机平台为macOS Apple M6，Godot4.7.2，Metal4.0 Forward+；与旧M5证据区分。
- 44项任务物理/状态门禁、69项旧训练场headless检查、20种子生成、6项原生射击/撤离检查通过。
- 60秒真实胶囊/镜头压力路线，1920×810：平均141.58fps，P95 8.397ms；沿途261.2m，最高脚底2.410m，11个路径点；约1.69GiB引擎视频内存计数。该基准补生命避免死亡，不冒充正常游玩。
- 原生静帧与脚本化演示视频交付。视频采用原生MovieWriter、真实按E与射击，但使用机位切换、敌人定点与剩余敌人直接清除，不冒充无人为干预通关。
- MovieWriter最初按project默认1280×800初始化，CLI窗口调整导致录制取景不匹配；后用临时独立显示配置（资源与缓存软链接）录制1920×810，不改project.godot基线。
- Headless无可听设备，不启动合成音频播放；仍验证WAV。原生退出仍有7个Texture RID warning，原日志保留，根因未定；不能宣称零警告或长时稳定。

**照片级目标仍未达到。** 主体资产、机械害虫、围界、终端等仍有明显简化；当前完成的是可玩且有电影化方向的第一轮样板，不是3A最终美术。用户验收pending。没有替换ML21贴图/几何、没有新增付费模型任务、没有打包发行或跨平台证明。
