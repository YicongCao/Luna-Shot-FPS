# ML04-光照与镜头效果

2026-11-15 · 在 ML03 六资产与原生路线验收后实施。Godot 4.7.2 / macOS / Apple M5 / Compatibility。

## 实现

- 18°低角度、略暖的太阳，黑色月空，弱冷环境光，固定曝光；没有月面大气雾。四个坡道入口灯、信号控制箱灯和塔顶标灯，共六盏短程无阴影设施灯；两个 UPDATE_ONCE 反射探针。灯具属于模块附属照明，不扩展主题建筑种类。
- LC01 能量贴图本身启用 Emission；两盏短程青色代理灯负责邻近表面受光。把自发光与局部补光拆成独立开关。枪械独立视口的主光方向随世界相机换算，世界遮挡会衰减主光；材料室保持独立布光。
- 场景使用 Compatibility 原生 Glow 高亮溢出。验证发现透明枪械视口的原生 Glow 不扩展 alpha：轮廓外亮度在合成时被裁掉。保留失败证据，枪械改为实际渲染画面的青色高亮提取、四分之一分辨率双向模糊、独立加法合成；不是用镜头纹理冒充 Bloom。白色陶瓷不进入枪械高亮通道。
- imagegen 生成透明横向光条和柔光/光学光斑两张素材；原图、提示词与运行时副本均保存。镜头效果由源位置、视角、屏幕边缘、距离和遮挡驱动，位于 HUD 下方；开镜强度为腰射 25%。枪械从实际 Emission UV 区域选取 32 个三角面样本，利用 TriangleMesh BVH 检查是否被枪身遮挡。F2 切换到总览相机；F3 释放整套场景光效，不带入材料室。

## 验证

[原生交互对照](../validation/lighting-v1/review.html) · [运行检查与性能](../validation/lighting-v1/native.json) · [像素比较](../validation/lighting-v1/pixel-comparison.json)。

13 项光效运行检查全部通过：真实网格遮挡能量区、能量关闭、设施灯关闭、太阳正对/遮挡/侧视/背对、枪械受阴影衰减、F2 及超宽布局。另保存出生、桥下、开镜、换弹、总览及 1600×700 截图。最终枪械 19 项无界面、29 项原生检查与材料对照通过；F3 材料室无关卡光晕残留、返回后照明恢复。光照接入后的 69 项无界面训练回归同样通过。

同机位对照确认：Emission 改变 435 个像素，局部灯改变 3,971 个像素；最终枪械 Bloom 在原轮廓外改变 246 个像素，设施灯周围的光晕环带平均增亮约 30/255。开镜光晕实拍强度比为 0.241（8 位量化下接近设定 0.25）。不是仅检查材质或环境参数为 true。

1280×800 原生窗口，同一条中央通道路线、每模式 600 个渲染帧、预热排除，以单调时钟测量：关闭效果 P95 **10.241 ms**，开启效果 P95 **10.136 ms**，满足 16.7 ms 目标。两者的微小差异属于测量波动，不能解释为加效果更快。这是短程比较，不代表长时间压力测试、其他 GPU、Web 或移动端验收。ML03 的约 149 秒真实胶囊路线已通过；光照修改不增加行走碰撞。

## 操作与复现

- F6：能量环；F7：Bloom；F8：镜头光晕；F9：局部补光。
- `tools/validate_lighting.sh`：原生运行、同机位截图、遮挡与像素检查。
- `LUNA_QA_OUTPUT=docs/validation/lighting-v1/rifle tools/validate_rifle.sh`：红点、命中、换弹、超宽与 F3 往返。
- 运行时实现：`scripts/lunar_lighting.gd`、`scripts/lens_flare.gd`、`scripts/weapon_bloom.gd` 和 `assets/lighting/`。素材来源：`art_source/lighting/imagegen-v1/`。

## 经验与边界

发光分三层验证：材质在没有补光时仍亮、局部灯让相邻表面受光、Bloom 在屏幕上越过轮廓；镜头光晕是第四层光学效果。透明视口是容易漏查的一环，必须看 alpha 和最终合成。淡出测试应按实际时间等待，不能假设所有显示器都是 60 Hz。

当前枪械 Bloom 专门识别青色能量高亮，若将来改变发光颜色，需要同步调整提取规则。设施局部灯无动态阴影，主太阳负责场景阴影；世界光晕遮挡查询使用建筑碰撞，极细格构与碰撞近似之间仍可能有差异。生成模型的局部表面起伏、折面和 UV 利用率限制仍存在，光照不会代替后续美术精修。

参考：[Godot Environment / Glow](https://docs.godotengine.org/en/latest/tutorials/3d/environment_and_post_processing.html)、[TriangleMesh 可见性查询](https://docs.godotengine.org/en/stable/classes/class_trianglemesh.html)。兼容性结论以本项目安装的 4.7.2 原生实测为准。
