# ML10 — 枪械回滚 ML06 与视觉基线

日期：2026-11-16。

用户查看 ML06/ML07/ML09 原生对照后明确认为 ML06 效果更好，要求回滚。恢复的是枪械默认资源选择，不对整个仓库执行 reset/revert；训练场、A 及环境、后期系统和设计文档继续保留。

## 实施

- 默认直接选用现存 ML06 几何、贴图、field_kit、动态弹药屏与两盏原有能量环局部灯，无重新建模或烘焙。
- 训练场和材料室共用选择逻辑；APPROVED 保留为技术门禁及防覆盖记录，不再决定默认版本。
- 显式 `--weapon-revision=ml06|ml07|ml09` 仍可比较；命令行优先于环境变量，`LS01_BASELINE=1` 优先于 `LS01_CANDIDATE=1`，后者仍选择 ML07。
- 更新项目约定、README 和三版对照页；后续枪械迭代以用户选定的 ML06 为基线。

## 验证

运行 `LUNA_QA_OUTPUT=docs/validation/ml06-rollback tools/validate_rifle.sh`，Godot 4.7.2 macOS Compatibility：导入无错误，headless 19 项和原生 29 项全部通过，实际加载版本均为 ml06。射击命中、换弹动作和回位、红点中心及可见性、超宽窗口、能量开关通过；F3 场景往返 5 项通过。材料检查室固定镜头、法线/材质响应、能量开关像素比较通过。

`tools/validate_weapon_selection.gd` 以 EXPECT_WEAPON_REVISION 指定预期，额外实测默认、候选、baseline 优先、显式 ML09、显式参数覆盖 baseline 共 5 种组合，均通过。该脚本实例化真实训练场并核对实际版本、资源根路径及分支，不只检查字符串选择。

[回滚后第一人称实机](../validation/ml06-rollback/11-range-hip.png) · [原生结果](../validation/ml06-rollback/rifle-native.json) · [材料室](../validation/ml06-rollback/01-hero-pbr.png)。本轮截图已查看，确认恢复 ML06 的分段弹夹、旧屏框与枪身轮廓；这些检查确认回滚和功能，不宣称解决 ML06 既有美术差距。没有长期性能测试、付费调用或远程推送。

## 经验

1. 更多几何、更多贴图、完整烘焙流程和技术通过不保证视觉更好；用户的同镜头实机比较决定默认版本。
2. 保留旧资源和显式版本选择，让视觉回滚只改选择层，避免撤销其他已完成工作。
3. 发布保护与默认选择需要解耦，技术标记不应越过用户的版本决策。
4. 后续先在 ML06 上做小范围对照，确认形状与材质确有改善再推广；历史验收不足与用户意见如实追加记录。
