# ML26 — T-Bug 机械结构与材质精修

日期：2026-11-18。

## 为什么继续

ML25暖雾已经落实，但原T-Bug近景仍明显由球体和细杆组成。不能用加强Bloom或雾来替代形体质量。本轮只精修害虫，不改变用户偏好的氛围与已完成的任务交互。

## 实际制作

- 程序构建切角厚装甲、实体倒角、密封底盘、固定螺栓/槽口、通风条、关节盖、执行器、踝轴、脚垫和嵌入式发光件。
- 六片可受损装甲和六腿根保持独立；保留三发击杀、胶囊、LOS与AI。
- 沿用已有工业涂层shader和历史imagegen磨损纹理。无新增Tripo/混元/imagegen调用；没有离线图冒充实机，也不声称新的高模烘焙。
- 新造型成为独立关卡/Benchmark默认；`QUARANTINE_BUG_STYLE=baseline`保留旧版。其余共享资产不变。

## 复查中修正

1. 玩家FOV插值覆盖诊断镜头，导致近景证据偏远：冻结诊断process并检查实际FOV。
2. 混合索引格式合并几何，脚垫和发光件丢失：实拍发现后统一索引格式、缓存转换，增加三角形守恒门禁。
3. 新ShaderMaterial损伤必须复制再修改；真实命中测试新增另一只未命中害虫材质不变检查。

这些中间问题有保留的原生图，不能把第一轮技术门禁通过说成完整几何验收。
