# ML24 — 实机 Benchmark 与全息终端交互

2026-11-17。用户追加要求：创建像宣传片一样展示场景与玩法的实时 Benchmark；UI 不写 Slogan、世界与 HUD 图标优先；任务进度使用 items 数量；按产品 UI/UX 思路重做终端指引，必要时使用设备投射的全息界面。

## 实现

- `launch-benchmark.command` 一键启动独立 `quarantine_benchmark.tscn`。约52秒实时镜头，九次真实射击击杀三只害虫、真实按E上电、实际胶囊撤离；结束可R重播、Enter实玩、Esc退出。其余五只在剪辑点清除，明确不是无人干预通关。
- HUD 去掉装饰英文标签，使用图标、弹量/生命和任务数量 `n/8、0/1、0/1`；增加终端/撤离屏内定位和离屏方向，敌人LOS不变。
- 全息面板是世界空间真实渲染、带边框与投射连接线的单一界面。清剿条件、唯一E操作、完成后的撤离提示分状态呈现；不再重复电源图标和HUD按键。
- 终端增加前侧、距离、注视、遮挡约束；转身/离开/松手/遮挡中断按住。完成数量由独立状态保存。
- T-Bug 增加真实命中驱动的短路、抽动、局部装甲损伤/偏移与残余电弧，保留原伤害与遮挡，固定效果预算，不新增追踪。

## 验证与修复

49项任务、69项旧训练场、6项原生capture、12项完整演示、11项实际键盘重播/实玩/暂停检查通过。电击/定位/全息专项见独立checks.json及原生图片。

修复了重播/切场景后对已脱离节点调用get_viewport导致的空引用；性能结果分清物理输出与逻辑UI画布；把仰视时身后目标错误指向天空改为下侧回转提示。保留早期失败记录，不改写历史。

无截图 Benchmark：1920×810，Apple M6 / Metal Forward+，预热4秒后测47.51秒，平均59.97FPS，P95 17.430ms。不是ML23的独立60秒行走路线，不能混用。

新增Tripo/imagegen调用0。原Compatibility训练场、ML21共享枪械资源和环境资源未覆盖。程序损伤不是完整物理破碎，技术通过不等于AAA照片级或新手可用性验收。7个Texture RID退出警告继续开放。
