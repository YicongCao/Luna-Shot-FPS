# ML20 — 混元高低模烘焙与默认枪械替换

日期：2026-11-17。用户要求基于两张概念图完成材质分区、烘焙、低模上色和 Godot 接入，替换 ML06 默认枪械。本轮没有调用付费生成服务。

## 完成内容

输入为 ML18 已归档的混元高模、低模 GLB 与 UV FBX；用户本次提供的三个文件 SHA-256 与归档完全一致，没有重复入库。高模 1,992,214 三角；FBX 低模 20,901 三角、单套 UV，栅格覆盖率约 70%。

1. **配准**：低模到高模刚体 ICP，平均误差 1.60 mm；高模到 ML06 游戏坐标做相似变换，缩放 0.7715，并翻转为枪口朝 -Z。
2. **低模法线**：平台自带自定义法线会让大平面鼓起、棱角发软。烘焙前清除这些法线，只在大于 30° 且已经是 UV 接缝的边设硬边（4,415 条），再使用面积加权法线。修复前后对照见 [low-normal-shading-compare.png](../validation/ml20-hunyuan-bake/low-normal-shading-compare.png)。
3. **烘焙**：Blender 5.2.2 Cycles Metal，selected-to-active，cage 外扩 3 mm，最大射线 9 mm。输出 4K 切线空间 NormalGL，以及 2K AO、位置图和表面法线图。
4. **材质分区与上色**：在共同游戏坐标中，从用户选定的 ML06 表面采样颜色并就近投票，再按两张概念图调色和修正：白色陶瓷涂层、炭灰框架、安全橙、黑色握把、枪灰线圈和青色能量环。移除 ML06 机匣侧面的黑橙警示斜纹，枪托改为炭灰，扳机改为橙色。磨损只来自烘焙曲率和 AO，掉漆仅占约 0.45%。
5. **运行时资源**：`assets/weapons/lc01/ml20/` 包含 `weapon.glb`（主体 18,794 三角 + 弹夹 2,107 三角）、4K `NormalGL` 与 2K `BaseColor`、`ORM`、`Emission`。贴图使用 GPU 压缩和 mipmap，法线贴图以法线模式导入。
6. **接入**：`weapon_asset.gd` 默认 `ml20`。弹夹挂到原 `P07_Cell` 换弹节点；红点、枪口、能量开关、Bloom、开火效果和枪械实验室保持原接口。

## 验证

Godot 4.7.2 原生与 headless 枪械 QA 均为 0 失败，覆盖 2 个网格、20,901 三角、贴图尺寸与 mipmap、红点居中/渲染、命中、换弹动画和超宽屏。枪械实验室 21 张截图完成；方案 C 脉冲电弧 headless/native 均为 0 失败；默认 `ml20`、`--weapon-revision=ml06` 与 `LS01_BASELINE=1` 选择均通过；场景切换无错误。证据见 [validation README](../validation/ml20-hunyuan-bake/README.md)。

## 限制与用户验收

- ML06 的 20 格动态弹量屏属于 ML06 附件，与新外形不匹配，ML20 暂不装载；HUD 弹量保留。
- 混元低模本身在部分窄倒角处仍有轻微起伏；本次修正了法线，没有重拓扑。
- 颜色区域来自 ML06 迁移和规则修正，少量零件交界可能与概念图不完全一致。ML20 没有新增可读刻字；现有凹凸字样仅来自高模法线。
- 性能只做了短时 QA 帧时间，没有做长时间成对性能测试。
- 本记录只代表技术与实施检查通过，用户美术验收待定。ML06 仍可通过 `launch-weapon-baseline.command` 回看。
