# ML25 — 暖黄末世氛围与同机位对照

实施：2026-11-17；验证归档：2026-11-18

## 目标

用户喜欢首轮偏黄体积雾的末世感。将这个偏好真正落实到当前清剿关卡和实时 Benchmark，而不是只记录偏好，也不回退 ML24 的数量 HUD、目标定位、全息终端和真实命中反馈。

## 实施

1. 新增独立 `atmosphere.gd` 预设，默认暖黄/灰金；`QUARANTINE_ATMOSPHERE=clear` 保留清淡对照。
2. 调整太阳光、雾散射、天空地平线与有限太阳角尺寸，保留冷色设施光和近处功能界面的分离。
3. 首次偏橙结果实际截图复查后降低复合饱和度，保留中间版证据。
4. 固定入口/ADS/终端/能源恢复四个机位，提供本地 HTML 切换；原生结果携带 atmosphere 元数据。
5. 修复验证脚本 `rg` 缺失时错误扫描失效的问题，改用系统 grep，共用 fail-closed 扫描函数；正常、报错、false检查、缺失日志四种返回码测试通过。
6. 重跑暴露全息淡入检查的帧数等待不稳定，改为按秒等待，不放宽原断言。失败与成功证据分目录保存。

## 验证与收益/损失

最终数据见 [ML25 报告](../validation/quarantine-atmosphere-v1/REPORT.md)，画面见 [同机位原生对照](../validation/quarantine-atmosphere-v1/review.html)。正式性能使用真实启动入口、无截图写入；编排和实玩衔接分别验证。

暖雾恢复了远景层次和压迫感，蓝色全息面板/能源更突出；代价是远处结构和背光虫体的暗部细节降低。不能因为技术通过就把这些取舍写成全面画质升级，更不能写成用户已认可最终版本。

## 边界与经验

- 原训练场、共享环境资产和 ML21 枪械未改变；无新增 Tripo 或 imagegen 调用。
- 暖色是美术方向，局部过曝、过饱和与操作可读性是独立问题，不能用整体冷化替代局部修正。
- 不以脚本退出0代替真实错误扫描；测试等待必须匹配运行时以秒计时的状态。
- T-Bug 形体、重复模块与部分表面高光仍有样板感；本轮不宣称照片级目标已达成。
- 原生 Metal 退出的7个 Texture RID 警告仍开放；用户视觉验收仍待定。
