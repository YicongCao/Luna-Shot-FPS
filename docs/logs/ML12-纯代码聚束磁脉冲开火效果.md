# ML12 — 纯代码聚束磁脉冲开火效果

2026-11-16。用户选择方案 A，要求纯代码实现。使用当前默认 ML06；枪械几何、UV、贴图和环境资产均未重建。本轮 imagegen / Tripo 调用均为 0。

## 实际效果

- 单发立即出现青白尖闪，35 ms 内消失；细直光迹指向实际射线命中点，65 ms 内消失。少量命中火花及局部照明在 100 ms 内归零，短于 160 ms 射击间隔。
- 能量环发光与既有补光随单发提亮并回落；新增一盏短距离、带阴影的枪口局部灯。F6 继续控制能量环，F9 控制局部灯，F7 控制既有 Bloom。射击本身的闪光/弹道不因关闭能量环诊断开关而被禁用。
- 腰射闪光沿枪管方向展开，开镜缩至 55%，并保留枪身自身遮挡。闪光轴向长度上限 0.58 m；近处命中时再按剩余距离裁短。长度不等于画面中的可见宽度，实际受透视及前护罩遮挡。
- 命中点有小青白亮点和四条向表面外侧飞散的短火花，其中一条暖色。打空不产生命中火花；没有烟雾、持续激光或新增伤害机制。
- 单发声音由代码生成 75 ms PCM 电容瞬态，游戏正常开火时播放；不导入音频素材。

## 实现与重要修正

[magnetic_pulse.gd](../../scripts/magnetic_pulse.gd)复用两个 ImmediateMesh、材质及一个瞬态灯，使用数学 UV 衰减生成细光带，无效果位图。世界弹道与命中残光留在场景空间，不随玩家移动；枪口尖闪挂在 ML06 的实际 Muzzle。声音只在初始化时生成一次。

[player.gd](../../scripts/player.gd)在成功消耗子弹、解析命中之后触发效果。原实现使用硬编码的近距离枪口点，并只在相机射线命中时检查遮挡。本次用实际挂点投影，通过两个相机的 FOV/视口尺寸映射到世界枪口位置；分别检查“相机到枪口”和“枪口到目标/远端”，包含相机朝空处时的遮挡。实际命中结果和视觉终点共用；冷却、空仓、换弹或阻止输入时均不产生新特效。

相机到枪口已被墙挡住时，隐藏视口枪口尖闪与新增局部灯，只保留墙上的命中反馈；枪口前方有近墙则缩短闪光。世界光迹保留深度测试。F2、暂停和重置会清空瞬态，F3 场景切换随训练场释放。

实施中暴露的问题与处理：

1. GDScript 经动态玩家引用取向量时不能自动推断类型，补显式类型后通过解析。测试检查日志中的 SCRIPT ERROR，不能只依赖 Godot 退出码。
2. 透明武器视口中的加法混合不适合直接承担可见闪光的 alpha 合成；枪口改为普通 alpha，世界弹道继续加法，后期沿用已有武器 bright-pass。
3. 隔离实拍证实：ML06 前护罩会遮住过短的轴向闪光。没有删改护罩，也没有关闭枪身深度测试；调整尖闪长度与宽度，让腰射可见，ADS 仍保持收敛。
4. 检查截图曾因冻结玩家过程而保留屏幕旧弹量；确定时刻截图改为先同步真实弹量，再冻结效果年龄。正常游戏仍由原流程同步弹量。
5. 近墙可能位于枪口之后、闪光长度以内；增加剩余距离裁短，而非仅检查枪口之前是否有墙。
