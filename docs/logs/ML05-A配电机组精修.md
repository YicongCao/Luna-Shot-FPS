# ML05-A配电机组精修

2026-11-15。依据概念图先完成 A 样板，不扩展环境资产种类，不增加 Tripo 消费。

把原来的一体箱体细化为六块顶盖、三扇带铰链/锁扣的检修门、两块后检修盖、真实凹入的三路接口舱、三根带护套和固定夹的线缆，以及安装脚和底座线槽。所有部件收在原 3.8×3.8×1.2 m 外包络内，继续占用 4×4 m 网格，40 个实例共享同一资源。

先保存旧版资源与 Godot 同机位截图，再本地分别构建高模和低模。高模 65,252 三角；低模 5,180 三角，较旧版 7,783 更低。固定 UV 后真实投射 Normal/AO、粗糙度、底色、金属度和诊断条发光，输出单网格、单材质、四张 2K 图。高模细节有明确结构来源，不以大量细分代替设计。

两个经验：倒角后应清除零面积三角再展开，避免无效 UV；金属 BaseColor 应投射纯颜色，不能把漫反射能量衰减烘进去。尺寸、背面剔除和线缆终点必须结合原生四侧截图检查。

UV 越界、退化和严格内部重叠均为 0，覆盖率 56.55%，非流形边为 0。20 种子和 188 项模块检查通过；69 项无界面、81 项原生训练回归通过，真实胶囊运行约 149 秒。独立视距 3/10/20 m 和关卡近景使用新旧相同机位，便于判断细节在游玩距离下是否有用。
