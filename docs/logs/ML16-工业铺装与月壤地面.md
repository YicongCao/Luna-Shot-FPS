# ML16 — 工业铺装与月壤地面

2026-11-16。用户授权先做8×8m样板，验证后推广全场。当前：8×8m样板及64×66m全场推广已完成，技术与实施视觉复查通过；用户实机美术验收待确认。

## 样板阶段

独立场景 scenes/ground_studio.tscn，启动 launch-ground-sample.command。B切换前后，F2总览；复用现有玩家、枪械和A，尺寸8×8m。左侧4m道路、右上A座基、右下单盖板及月壤边缘。A四个足座坐标来自a_refine源码，地面座片按其实际位置及模块朝向安装。

新增三套2K可平铺材质，固定种子20261116，源为16位高度场与程序配方；只声明从高度场计算切线法线，不冒充高模投射烘焙。没有Tripo/imagegen付费调用，也没有整场独占大UV/浮点Position EXR。铺装接缝2×4m，比旧1m网格安静；盖板真实分框/盖/提手/十字紧固件，地面保持原碰撞平面，装饰高差不超过22mm。

第一轮铺装凹坑过强、金属太黑，且沿用了跨度过大的训练场反射探针，出现探针边界色带。减弱微高度、校正钢表面底色，并将样板探针覆盖调整为完整8×8m区域；前后截图使用相同光照。失败画面保留在 first-pass，修正后正常尺寸能分清粗糙铺装、钢盖和粒状月壤。大平面不铺满损伤，不借过曝/Bloom掩盖细节。

原生样板检查通过：真实玩家沿道路往返、跨检修盖和月壤，无卡脚/碰撞高度变化；同机位前后、关闭Bloom、微法线像素响应与另一方向掠射光已记录。样板施工源约几十MiB，避免大规模浮点烘焙中间文件。本段记录样板阶段当时状态，最终整合结果见下文。

## 全场推广与最终验证

样板提交631d3fe后，复用同一套材质与盖板，默认场地使用40组A座基和8个道路检修盖。遮罩从实际布局/路线在启动时生成，512×528单通道、8像素/米；不同种子自动适配，不依赖一张写死的默认地图贴图。中央8m十字、外围/支路、出生区和设备范围保留铺装，边缘留0.3m保护余量。布局、主题模型与碰撞未修改。

为三套材质补齐GPU压缩、mipmap、各向异性过滤；真实加载的9张2K贴图均检查压缩和mipmap。粗糙铺装/颗粒月壤与钢盖形成区分，黄色反光条沿用ML15。全场不额外散布大量碎石，样板小碎石作为地表细节保留。

大地面仍暴露了两个反射探针的漫反射边界：尝试关闭RADIANCE并未去掉色带，最终使地面IRRADIANCE与WorldEnvironment的环境光颜色/能量同步，保留太阳、局部光与镜面反射；其他资产/探针配置不变。样板仍使用适合8×8m范围的单探针，前后相机和曝光一致。[Godot 4.7着色器说明](https://docs.godotengine.org/en/4.7/tutorials/shaders/shader_reference/spatial_shader.html)支持分别覆盖环境漫反射与镜面辐射；实际效果以本项目原生截图验证。

20种子遮罩确定性/4m通行带采样通过，样板21项、全场地面24项、原生关卡81项、枪械29项通过，另完成F3往返、材料对照、靶击倒和超宽窗口。A/B1/B2/C/D/E、ML06枪械、ML14风扇代码和energy-layout.json与591b1f8保持一致。默认场景在门禁通过后生成published=true，运行时不依赖打包扩展名为APPROVED的文件；GROUND_BASELINE=1可返回ML15地面。

同机同近设施路线，预热后60秒、1600×1000、默认VSync：P95 9.866→9.967ms（+1.02%），低于+10%门槛；纹理内存增加约32.3MiB。样板提交631d3fe；最终全场实现、证据与本条日志一起提交，最终提交号在交付回复中报告。

## 有效经验与边界

- 地面先用独立样板判断尺度和材质层级，再推广。铺装安静，盖板承担机械细节，月壤集中在非通行空隙；避免地面和设备争夺注意力。
- 规则地面不必走远端完整模型生成。高度场、可平铺PBR和少量程序几何足够验证方向，本轮付费调用0；没有生成大幅浮点Position EXR。
- 近景通过不代表远景通过。显式设置并验证mipmap/压缩，不能只写各向异性过滤就假设已有mipmap。
- 颜色断带可能来自光照采样，而不是UV或贴图。分别检查镜面和漫反射环境项，保留直接光照，避免为修地面而无意改变A和枪械。
- 实际胶囊与布局遮罩分别验证。视觉细节不引入新台阶，保护道路宽度；不同种子的设备位置不能沿用默认种子的遮罩。
- Godot脚本解析失败可能仍返回0；检查日志和新生成JSON，不只依赖进程退出码。
- 微接缝/凹坑是法线，无真实位移；极低视角仍能看出平面。检修盖不可打开，使用痕迹保持克制。技术和实施视觉通过不替代用户美术验收。
