## 迭代经验

1. **先拆验收条目，再生成。** 显示屏、沉孔、铜排线、散热片和材料磨损分别检查，能防止某个漂亮视角掩盖缺件。
2. **布尔运算作用于独立闭合零件。** 首轮对已合并的多层外壳整体加工，破坏了其他表面。改为每块顶盖单独加工后再合并；实机四侧及近景复查，不能只看脚本退出码。
3. **保留 UV 与重新烘焙不矛盾。** 锁定的是布局和对应关系；几何、硬边或顶点法线变化后仍需更新切线空间法线与 AO。新附件使用独立 atlas 更容易控制风险。
4. **微细做旧优先用贴图。** imagegen 提供凹坑与划痕图案，本地程序负责掩码、尺度、法线合成和材质响应；深槽、沉孔、轮廓边缘继续用几何。这样能压缩人工雕刻和重复高模工作的成本，但本轮没有做可量化的工时节省对照实验。
5. **生成图不是即插即用的技术贴图。** 首次微法线过强，金属像锤纹板；降低幅度并抑制背景颗粒后再比较。必须检查掠射光和实际游玩距离，不以“细节更多”作为唯一指标。
6. **显示内容由游戏状态驱动。** 不把固定弹量烘进贴图；用真实弹量、空仓、换弹结束和重置逐项测试。
