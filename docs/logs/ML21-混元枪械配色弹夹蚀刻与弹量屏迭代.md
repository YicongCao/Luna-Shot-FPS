# ML21 — 混元枪械配色、弹夹、蚀刻与弹量屏迭代

日期：2026-11-17。用户要求迭代 ML20，补三个短板：弹量屏、岩石灰改深藏青黑、弹夹未涂橙的表面；两侧无意义的凹陷蚀刻直接打平；检查并处理不清晰、不锋利的线条。磨损暂不补。本轮没有调用付费生成服务。

上一对话因上下文超限中断，当时只完成了蚀刻定位、斜面测量和工具改名。本轮接着完成。

## 完成内容

1. **新版本而非覆盖**：`tools/ml20_weapon` 改名为 `tools/hunyuan_weapon`，由 `paths.py` 的 `REVISION` 决定输出。ML21 源与烘焙在 `art_source/weapons/lc01/ml21-hunyuan-refine`，运行时在 `assets/weapons/lc01/ml21`。ML20 运行时资源保持不变，可从提交 `2dfee1c` 复现。
2. **蚀刻打平**：两侧各 3 个区域（机匣铭牌、斜线刻痕、前护罩小刻痕），用周围一圈拟合倾斜侧板平面，把凹陷顶点投影上去，高低模都处理。随后合并重合顶点、删除折叠碎面和被覆盖的共面叠层（否则会 z-fighting 形成暗块），再给该区域统一平面着色法线，最后重新烘焙。
3. **线条锐度**：高模改为 35° 角度限制平滑，再投射法线，真实折边不再被抹圆；4K 法线做反锐化。
4. **配色**：机身深藏青黑 (28,35,46)，握把更黑、更糙，线圈枪灰不变。
5. **弹夹**：按弹夹 UV 岛整体判断，壳体全部安全橙，端块与底轨为机身色，消除下倒角上橙灰混杂、左右不对称的问题。
6. **弹量屏**：`weapon_field_kit.gd` 新增仅屏幕模式。ML21 把 ML06 的 20 格动态屏按 0.7 倍装在后机匣斜面上，与 HUD 弹量联动，不挡红点。
7. **默认**：`weapon_asset.gd` 默认 `ml21`；`--weapon-revision=ml20` 和 `ml06` 可回看。
