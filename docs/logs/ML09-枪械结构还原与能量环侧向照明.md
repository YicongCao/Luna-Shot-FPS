# ML09 — 枪械结构还原与能量环侧向照明

日期：2026-11-16。状态：实施中，用户验收待定。

## 问题与决策

用户指出 ML07 材质改善的同时丢失了 ML06 / 概念中的机械形状：规则对称屏、枪托少了一层倒角、接口变直、瞄具少角及前后鳍片、弹夹成了平板。以 ML06 为弹夹结构基础，受控几何重建并保留 ML07 材料分层，重新打开上述视觉检查。概念与原生图不能互相替代。

## 阶段一：结构

独立 `ls01-refine-v2` / `ls01_v2` 候选，保留 ML06/ML07。真实宽倒角截面、榫接式黑白斜切、八角瞄具及前后各三片安装鳍片、下移端点的异形六边屏及同形底座、分段弹夹和开窗护罩。所有新增件保存高/低/cage，主体与附件重新展UV。运行时选择 `--weapon-revision=ml06|ml07|ml09`，不传参数仍使用已验收候选逻辑。

灰模检查中发现弹夹端部螺钉悬空，改到有面板承托位置；护罩下肋补内支撑条，末端补接合套筒。低模拓扑、正体积、cage对应与UV严格重叠检查通过。原生Godot灰模证据在 `../validation/ls01-refine-v2/`。

## 经验

- 材质改善不能抵偿轮廓退步；先把“几个角、几层面、几处连接”写成可观察的结构条目。
- 宽倒角应是独立截面带；窄倒角修饰只能负责高光，不能吞掉原有面。
- 高模浅槽可以烘焙，但端盖、卡扣、镂空、弯曲和装配连接必须留在低模。
- 版本目录不仅是输出参数：运行时材质、审计、截图与发布也必须选择同一版本，避免串用旧UV贴图。
- 当前阶段不宣称最终视觉验收；材料、补光和性能后续验证。

## 第二次法线复查

在反侧掠射光下发现弹夹面板的斜向明暗与缺角槽痕。低模平面逐角法线点积检查定位到三角化修改器默认未保留custom normals：部分法线与几何平面法线点积仅0.792。ML09三角化改为`keep_custom_normals=True`后，同一位置提升到0.999977，未动轮廓或添加伪补丁。旧body/kit烘焙缓存作废，重新烘焙；增加源低模与实际glTF导出面的法线检查。该项再次说明“已三角化”不等于“烘焙切线输入稳定”。修正前图和检查日志保存，未将其当作做旧通过。
