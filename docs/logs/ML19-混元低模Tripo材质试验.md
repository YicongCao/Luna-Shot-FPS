# ML19 — 混元低模 Tripo 材质试验

2026-11-16。用户确认一次20积分HD PBR任务，保留混元低模造型及UV，要求Godot同机位比较和commit。

## 完成内容

以ML18归档的混元`pbr.glb`为输入（20,901三角、已有UV和底色），调用Tripo texture v3.5一次，任务`ee8cdeda-8240-4e85-b11f-b7677d662500`，实际20积分，0重抽。得到4K BaseColor、Normal、MetallicRoughness三张图及GLB；未调用减面、Smart UV、模型生成或本地几何重建。

逐三角面角点匹配证实：20,901面全部保留绕序与几何，UV差值0；逆转服务居中及等比归一后最大位置差4.88e-8源单位。顶点17,971→17,981是拆点，不能只凭顶点数误判为改形。原文件哈希不变。

顶点法线并非精确保持：18个零法线角点被替换；有效法线角点中6个方向差超过0.1°，最大26.17°，其余变化很小。该差异公开记录，不把几何/UV通过写成全部数据不变。

Godot 4.7.2 Compatibility独立材料场景完成36张原生截图：混元原底色、混元＋Tripo PBR、ML06，同机位、曝光及两组光照；最终材质、灰模、法线关闭和仅底色。48条导入/截图/统计记录通过，保形保护测试5项通过。未更改默认ML06、环境或游戏代码。

## 视觉结果与经验

- **保留网格生成PBR可行，但不是自动美术升级。** 反射和微表面有了，弹夹/枪托等造型也保留；但部分白色区被重绘成深色，整体偏亮滑，原低模的波浪式高光被放大。
- **把底色与反射分开看。** 仅底色图证实色块改变；法线关闭后起伏高光仍在，不能把所有缺陷归咎于新Normal贴图。
- **工具承诺不代替输出核验。** 此接口没有锁UV参数，这次实测保持，不代表未来任务必然保持；逐面位置/绕序/UV验证比只看面数可靠。
- **统计需解释。** 输出增加拆点，几何仍相同；服务法线变化不能隐藏。UV不变可支持后续在同一模型上独立试验颜色和粗糙度，不必整枪重做。
- **PBR通道齐全不等于材料正确。** 涂漆、裸金属、橡胶和油膜仍需要艺术判断。此次无独立AO/Emission，不把MR全白红通道叫作AO烘焙，也不把服务bake选项叫作混元高低模精确投射。

候选保留，不推广默认，不自动付费重抽。用户验收待定。下一步若继续，优先在现有UV上保留原混元色块并局部校正粗糙度/金属度；不要以修材质为由重新减面或重建。本里程碑仅记录试验，未实施上述后续修改。
