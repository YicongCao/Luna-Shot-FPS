# ML27 — 实机特写景深与实体检修灯

日期：2026-11-18。

## 目标

让ML26机械结构在实时演示中可见，而不是通过更浓的雾或更强Bloom掩盖问题。保留暖黄美术方向，正常战斗/ADS/终端保持清晰。

## 制作与纠偏

1. T-Bug特写改为三分之四视角，使用CameraAttributesPractical的原生远景景深；切镜立即恢复原相机属性。
2. 独立图片复查指出：景深能分离主体，但暗部仍读不清、新镜头裁脚、旧镜头更有设施尺度。没有把这次复查当成用户验收。
3. 扩大特写构图余量，保留开场宽镜头；特写期间调整其他冻结害虫站位，交战前恢复，避免近景相机穿入另一只虫体。
4. 在既有屋架下安装一盏带支架/灯壳/扩散面的检修Spot，正常清剿和Benchmark共用，固定位置、有阴影、雾能量0。初次远距离能量不足，原生A/B后调整为24；不抬全场曝光。
5. 分别保留旧机位、仅改构图、构图+景深、构图+检修灯、最终组合五组原生帧。关闭景深检查灯光收益，防止以模糊掩盖形体。

## 验证

[分项对照](../validation/benchmark-lens-v1/review.html) · [完整报告](../validation/benchmark-lens-v1/REPORT.md)

五组诊断各5项通过；49项任务、69项训练场、20布局种子、6原生、24反馈、12演示检查通过；操作/镜头隔离/实体灯源衔接增至17项并通过。实际无截图入口130.605 FPS / P95 9.421ms，限当前macOS/M6/Forward+运行条件。

原生实拍确认主体边距、正常ADS清晰和挂载灯源；不以测试通过替代视觉判断。特写牺牲部分背景细节，新增一盏阴影Spot有性能成本；模块重复、远景棱角和非IK步态仍开放。用户视觉验收待定。

## 边界

原Compatibility训练场、共享资产、暖雾/全场曝光不变；无新增Tripo、混元或imagegen调用。景深只在Benchmark特写启用，检修灯是关卡实体。编排演示不是无人干预通关。7个Texture RID退出警告仍未定位。
