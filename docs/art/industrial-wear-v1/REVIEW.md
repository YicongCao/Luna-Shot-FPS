## 弹药指示条

位置严格对应用户红框：瞄具后方、枪托前方的机匣后上部斜面。嵌入暗色屏幕与窄边框，不占用瞄具透镜。

当前 scripts/player.gd 的 CAPACITY 为 20。实现时用 20 个分块（每 4 格一组），一发对应一格，数字读数冗余提示。图中 13 / 20 是外观示例，生成图格数不作验收依据。建议常态青色、剩余 1–4 发琥珀色、空仓全部熄灭并显示 00；换弹完成时才恢复弹量。具体颜色可随用户调整。

由真实 ammo / CAPACITY 驱动独立屏幕材质或着色器；不要让 Tripo 将固定数字和光条烘焙成不可变贴图。控制 emission 与 Bloom，分块间隙必须清晰。外壳可生成，动态内容由程序负责。

## 保留 UV 的锐化路线

已检查当前生成/烘焙脚本和现有 UV 审计：A 低模 5,180 三角，已记录 UV 越界与退化三角均为 0；A 构建脚本会重新 smart_project / pack，因此不能直接重跑它来声称保留原 UV。LC01 使用切线空间 NormalGL 烘焙。本轮尚未做逐边几何诊断或锐化试验。

1. 在源文件副本诊断：关闭法线贴图、统一材质并用掠射光，区分贴图模糊、平滑法线串面、几何本身圆钝。不要对能量环、线缆等曲面做全局硬化。
2. 若只是着色问题，按面夹角和零件范围设置硬边/自定义加权法线，保留窄倒角；这能改善平面高光，但不能改变真实轮廓。
3. 若倒角几何确实宽软，选择局部平面拟合与约束顶点移动，保留面连接和逐角 UV；不能保持拓扑的区域另做局部替换件，不进行全模型自动重网格、减面或重新 UV 打包。
4. 冻结低模三角连接、UV 层及逐角坐标，记录修改前后哈希和差异。UV 坐标不变仍可能因顶点移动而产生纹理拉伸，需要棋盘与原贴图双重检查。
5. 改变几何、硬边或顶点法线后，沿原 atlas 重新烘焙 Normal/AO，并检查接缝、投射穿透和背面剔除；不承诺旧法线贴图可无损直接沿用。新增屏幕、排线与散热片可作为独立网格、独立 UV，避免重排现有主体。
6. 验收包含 UV 差异、轮廓、同镜头开关法线贴图对照，以及 Godot 开镜/腰射/换弹时屏幕可读性与弹量同步。后续用户确认后才执行此路线。

依据：[Blender Weighted Normal 文档](https://docs.blender.org/manual/en/latest/modeling/modifiers/normals/weighted_normal.html)说明加权法线与 Keep Sharp 控制着色；本项目 AGENTS.md 要求改变朝向或顶点法线后重新烘焙。
