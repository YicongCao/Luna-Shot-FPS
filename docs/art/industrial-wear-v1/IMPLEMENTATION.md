## 制作与迭代顺序

1. 保存现有 GLB、贴图和 UV/拓扑基线；新来源目录使用独立版本，不覆盖 pipeline-v2 或 A-refine-v2。
2. Tripo 只生成一组不带材质的工业附件高模（排线、固定夹、散热片），其余精确配合面与屏幕本地制作。生成结果必须逐项审查，缺失或圆钝处本地重建，不自动付费重抽。不重新生成整个 A 或枪械。
3. 本地制作附件低模、独立 UV、高低模烘焙。主体保持原 atlas；对 A 顶盖新增凹槽和沉孔采用高模细节投射。纹理细节与动态显示屏分离。
4. 主体倒角诊断与局部修整，记录逐角 UV / 三角连接差异；法线变化后重烘焙。既有颜色可保留，Normal/AO 不直接套用旧版。UV 不变不代表不存在几何引起的拉伸。
5. 材质磨损使用可复现种子、接触区与边缘权重。划痕同时影响颜色和粗糙度，深划痕才影响法线；禁止全模型均匀噪声。
6. 接入真实 ammo / CAPACITY。开火每次减一格；空仓不出现负值；换弹完成才补满；F5 重置同步；F3 往返、开镜、换弹动画均不丢失显示。
7. 固定相机逐轮截图并记录失败项、修改与复查结果。只有全部必需项通过才交付完成报告。

## 实机证据矩阵

- 枪械：腰射、开镜、左右侧、后上方屏幕近景；20/13/4/1/0弹量；换弹前中后、F5、F3往返。
- A：前/后/左右/顶部、接口近景，3/10/20m及40实例关卡；增加划痕后检查远景噪声。
- 材质：同镜头 final / normal-off / constant / clay，区分贴图与几何贡献；掠射光检查槽、沉孔、排线和片间隙。
- 光效：能量环、红点、屏幕分别检查；Bloom 开/关、超宽窗口、不遮HUD。
- 回归：现有枪械、光照及地图脚本；局部新增几何不得影响碰撞与训练动线。

每项记录格式：ID → 首轮截图 → 问题 → 修改 → 复查截图 → 自动检查结果 → 通过/未通过。离线图和 Tripo 预览不能替代 Godot 实机。
