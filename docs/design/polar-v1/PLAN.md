# ML35 · 月球南极采冰站

单人 PvE 撤离切片。新主场景 `scenes/polar_extraction.tscn`，独立于 64 × 66 m 训练场与清剿演示。决定不是杀多少，而是**带什么、走哪条路、是否值得继续运货**。

## 空间与回程

- 着陆坪位于 0 m 标高，货梯中层 −8.5 m，钻井台 −17 m。初始第一人称先看见有舷窗的撤离船，也能看见连向钻井的架空索束；到坑缘可从栏杆间看到工作台。头顶不铺持续雾层。
- **西侧生活舱**：沿坑壁的两段封闭斜廊带连续碰撞，侧窗允许重新辨认坑底钻塔。中层有一次性补给和通往货梯的折转检修桥。开着的门不阻断流程；舱内风机与结构传来的轨道声用于区分有压/真空。并无气体模拟或氧气倒计时。
- **东侧检修台**：七级独立踏台，高差约 2.85 m；向下可短落，向上要选择起跳时机。只带记录匣能原路攀回。人工重力取 4.8 m/s² 以平衡第一人称漂移；不是月球 1.62 m/s² 的物理模拟。空中转向弱于地面，过长自由落体会伤害生命支持。
- **货梯**：初始停坑底，取回记录匣后才供电；不拿冰芯也可以坐。货台和厢内开关真实移动，随梯运送玩家及箱体。中层停车后可继续上行，也可离开货台穿生活舱回去。未装船的货不算完成。

## 任务与战斗

1. 走生活舱或检修台进入钻井区，面向实体记录匣按 **E** 拿取；没有击杀门槛。
2. 如要带走冰芯，面向箱体按住 **E**，箱体沿轨道驶向坑底货梯。登梯分别到中层和上层；上层用接收台把同一个箱体转运到船外货位。
3. 只需记录匣就能从实际舷梯进入船舱，面向控制台按住 **E**。左右舱门合拢，通风声恢复；玩家能转向舷窗，不切演示镜头。结算按记录匣与实际装船冰芯计件。

- **巡检轨车**在坑底设备上方运行，灯色和声音先警告再放电；后半段锁定落点，玩家可离开射线、借真实机柜遮挡，或用脉冲工具停机。它不满图追人。
- **采样机械臂**只在货梯西侧中层平台划过已警示的采样范围；留在梯内安全。可以等窗口、从其他路离开或打停驱动座。两种机器都按碰撞/视线和时间窗结算，无远距穿墙伤害，无强制清场。
- 空旷真空区无远距空气传声；短促的提示只给同一连接甲板上的玩家，舱段可听到结构共振和风机。不是声学求解。

## 建模与验收约定

全部新增几何、材质和音频由 GDScript/Godot shader 构建。没有 Blender/GLB 新资产，没有 Tripo、混元或生图调用；既有场景/枪械仍在旧入口。目标是照片级的尺度、材质和照明，不用浓雾掩盖简化几何。视觉评估要分别看出生/坑缘、中层、钻台细部和船舱；截图必须来自 Godot，分镜截取不算人类首玩。

用 `./launch-polar.command` 或编辑器 F5。`tools/validate_polar.sh --native` 复现任务门禁、构图帧及硬件测量；默认脚本不覆盖任何已入库历史证据。
