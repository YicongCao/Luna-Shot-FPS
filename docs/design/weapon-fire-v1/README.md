# LS01 开火效果：三个设计方向

2026-11-16。基于ML09实机截图，由内置imagegen生成三张概念图；本轮只制作方案，未修改模型、材质、伤害或运行时代码。图中局部枪体/构图有生成偏差，后续实施以ML09真实几何及挂点为准，不按概念图重建枪身。

当前`scripts/player.gd`的单发间隔为0.16秒（约6.25发/秒）。下面的时长是待实机调校的设计初值，不是已测试结果。三案共用20发弹量、真实命中点和当前射击机制；“励磁”表示开火瞬间的视觉响应，不增加玩家按下开火后的等待时间。

## A — 聚束磁脉冲（推荐先做）

![A 聚束磁脉冲](A-focused-magnetic-pulse.png)

**感觉：精准、短促、机械响应明确。** 能量环沿枪管方向迅速提亮，枪口出现小而尖的青白色闪光，细窄光迹指向命中点，随后断成少量残光。枪口只占很小的视野面积，让瞄准、铜管和机匣细节继续可见。图中长光线代表一个短时曝光瞬间，不是常驻激光束。

建议节奏：0–15ms能量环脉冲；0–35ms枪口尖闪；光迹约40–70ms；局部补光与残光在100ms内归零。命中反馈是一个小白核及少量朝表面外飞散的粒子。声音可用短促电容“啪”叠一层机械咔嗒，强化离散单发。

实现建议：尖形发光卡片/短锥体、细窄弹道带、少量粒子、一条短补光曲线。复用已有侧向灯与横向光晕，让开火时提亮后快速回落。资产量和调校复杂度相对低，适合当前连射及开镜。

风险：光迹过粗或寿命过长会变成激光水管；枪口白核和Bloom必须限制尺寸，不能吞掉目标。

## B — 压缩等离子

![B 压缩等离子](B-compressed-plasma.png)

**感觉：有体积、压力和重量的能量释放。** 枪口先出现一个紧致亮核，喷出带透明青色外壳的短能量团；同时脱落一圈小型椭圆等离子环，边缘迅速散成薄片状余辉。青色反光覆盖前护罩内侧、机匣和弹夹上沿，突出枪械表面的材质差异。

建议节奏：0–20ms亮核收束；20–60ms能量团脱离；60–110ms外环扩张并破开；150ms前基本消失。命中表现采用小型光斑与向外散开的薄能量片，声音可用低频冲击叠短促嘶鸣。

实现建议：两到三层透明发光曲面/序列贴图、一个变形环、少量短尾迹粒子，分别控制白核、透明边缘和补光。能量团只是弹道表现，不默认把当前即时命中改成慢速物理弹丸。相对A需要更多贴图和透明叠层调校。

风险：当前160ms射击间隔下容易累积成雾团；必须限制同时存活的环与残光、设置总亮度上限。月面场景不采用向上翻滚的火药烟，图中丝状部分解释为发光等离子残迹。

## C — 脉冲电弧

![C 脉冲电弧](C-pulsed-ion-arc.png)

**感觉：干脆、躁动的工业高压放电。** 枪口到命中点之间出现一条窄幅折线电弧，少量转折点闪亮，最多附带两三条很短的分叉；能量环附近有局部跨接小电弧，呼应铜管、钢制夹具和散热结构。电弧不穿过瞄具和弹药屏。

建议节奏：0–15ms线圈附近局部放电；主电弧可见约25–50ms，形状只跳变一两次；80–100ms内余弧熄灭。命中反馈用几个细小放射状电火花，声音为短促电气爆裂，避免持续嗡鸣。

实现建议：沿真实命中线生成少量折点的发光带，以固定随机种子限制横向偏移；主干和短分叉分开管理，逐段淡出。几何资产成本低，但时序、抗闪烁和透明重叠的调校复杂度中等。

风险：分叉太多会遮挡，持续时间太长会像电击束；只表现一次射击，不引入自动追踪、连锁伤害或电弧跳向其他目标。

## 共用约束与选择建议

| 维度 | A 聚束磁脉冲 | B 压缩等离子 | C 脉冲电弧 |
|---|---|---|---|
| 主要形状 | 尖闪 + 细光迹 | 圆润亮核 + 薄外环 | 窄幅折线 + 短分叉 |
| 观感 | 精准、快速 | 厚重、能量充足 | 高压、电气躁动 |
| 连射可读性预期 | 最好 | 需重点限制残留 | 需控制闪烁与分叉 |
| 相对制作/调校成本估计 | 低 | 中高 | 中 |
| 优先用途 | 默认射击样板 | 更强能量释放的风格候选 | 工业电气风格候选 |

建议首先选择A完成一套枪口→弹道→命中→消散的实机样板。若更喜欢B的体积感，可在A的短促节奏里加入一个很小的B式外环，不同时叠加三套完整主效果。三案均是视觉候选，不要求增加新射击模式。

实装时，枪口效果跟随实际武器挂点，远端弹道/命中效果处于世界空间，弹道指向当前真实命中点；检查贴墙时的遮挡以及两个空间之间的对齐。开镜时降低枪口外缘/Bloom/光晕面积，保留红点和目标。固定曝光下先关闭Bloom验证形状和局部照明，再恢复后期，连射20发检查是否累积过曝。现有枪身磨损、弹量屏、钢/铜/涂层差异应继续可辨。
