## 执行阶段与门禁

1. 概念与规格：保存基线哈希、参考图、提示词、已知偏差、规格及费用方案，阶段 commit。用户确认视觉方向后推进。
2. B1 样板：最终输入 dry-run → 单次 Tripo → 下载 → 本地精确高模 → 保形灰模检查 → 低模/UV/cage → 烘焙 → 分层 PBR → 四角红灯 → 原生对照。未达到保形与视觉条件时停留本件修正，不扩散。
3. B2：同一完整流程，保留原风扇动画、挂点和护罩碰撞；三处安装孔不得叠加第二套护圈/背板/叶轮。若候选仍含风扇网格，去除后再烘焙。
4. C、D：分别完成完整流程，优先恢复通行面、支撑和开放连接端，再处理细节和蓝色灯槽。
5. E 与设施整合：完成桁架、天线、柜体、橙色警灯；整合黄色标线与距离筛选补光，替换旧固定坐标设施灯。
6. 逐件通过后发布默认资源；候选失败不得覆盖默认。每个已验证阶段分别 commit，并更新 ML15。用户美术验收单列，不能以技术成功代替。

## 资产与烘焙契约

- 保留原运行时模块路径与尺寸；制作源采用新的 environment 精修版本目录，具有 .gdignore。禁止原地改写 pipeline-v1。
- 入口支持模块、阶段、固定种子、候选输出目录。清单记录源哈希、零件与材质绑定、UV 版本、高低模/cage 配对、纹理与挂点。
- 高模先明确结构；低模保留剪影、穿孔、片间空隙、管路弯曲和桁架。小凹坑/浅划痕/微倒角交给烘焙。已合格保留件不无故更换 UV。
- 固定低模三角化、逐角法线、UV 和切线后按组使用独立 cage；几何/UV/法线变化必须重烘焙。输出 NormalGL、AO、Curvature、Position、World Normal、Material ID，辅助图不强制加载运行时。
- 4K 制作母版、2K 运行时；BaseColor、ORM、NormalGL 与独立发光遮罩。ORM/法线按线性数据处理，启用 mipmap/各向异性过滤，检查引擎切线与背面剔除。
- 底材→涂层→露底→划伤/凹坑→局部油污→灰尘/氧化。掉漆同时改变颜色、粗糙度和金属度；完整漆面、锈蚀和灰尘为非金属。禁止沿用整件锁定金属度/压缩粗糙度的旧处理。
- B1 ≤20k、B2 静态主体 ≤20k、C ≤12k、D ≤16k、E ≤24k 三角。B2 现有风扇另计 15,588 三角/塔。动态灯具另列统计。

## 灯光约定

- B1/B2 每塔四角红灯：12×4=48，2 s 周期，亮约0.3 s，短渐入/出；同塔同步、不同塔固定相位偏移。
- C 每侧2段×2实例=8，D每侧3段×4实例=24，共32段蓝色常亮灯；D斜坡2段+平台1段/侧。灯罩发光和结构受光分别验证。
- E 顶灯：每秒一圈的方向性橙色亮区，叠加每秒一次短脉冲，Spot 同步扫过邻近上部结构；不添加概念示意中的空气光锥。
- 所有灯罩远景保留；实际局部照明按距离筛选，最多8个Omni+1个警灯Spot。各模块使用局部挂点，移除旧世界坐标坡道/顶灯重复光源。F7控制Bloom；暂停冻结闪烁/旋转相位，恢复继续。
- 黄色标线采用非金属反光漆、独立粗糙度和轻微磨损；在太阳/灯光下随视角形成高光，暗处不发光。射击线和主通道边缘分段薄网格，不添加碰撞，避免深度冲突。沿用现有反射探针，不制作镜面地板。

## 验收

同机位灰模、剪影、四侧及3/10/20 m对比；写明收益与损失。检查B塔4×4 m占地、C/D步行面2.4 m、桥下净高≥2.2 m/净宽≥3 m、E原底座与天线包络。真实玩家胶囊验证坡道/连接/桥下与护栏。

同曝光日照、掠射和暗区，先关闭Bloom验证反光漆/灯罩/局部受光，再开启Bloom；记录红灯完整周期、蓝灯近景、橙灯旋转及闪烁。检查背面灯、遮挡、不穿墙、暂停恢复、F5与种子重建。

运行 tools/validate.sh、tools/validate_rifle.sh、tools/validate_lighting.sh、tools/validate_b2_fans.sh；20种子、F2/F3、超宽、枪械/靶保持。证据进入新目录，避免覆盖历史截图。

同机同路线预热后测60秒帧时间/P95、三角/材质表面/纹理内存；P95比基线增加>10%则优化后重验。最终区分技术通过、实施视觉复查、用户验收。
