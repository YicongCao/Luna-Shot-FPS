# ML35 · 南极采冰站实机验证

2026-11-23 · Godot 4.7.2 stable / macOS / Apple M6（Apple9）/ Metal Forward+。运行入口 `launch-polar.command` 或编辑器 F5；旧 Compatibility 训练场仍用 `launch.command`。查看[原生图集](review.html)或[关卡设计](../../design/polar-v1/PLAN.md)。

## 验证结果

- **84 项任务及物理检查通过。** [原始日志](mission.log)；固定 60 Hz，共 14,952 个物理步。包含记录匣、选带冰芯、半途弃货、两级货梯运送胶囊和实体箱体、箱体扫掠净空、坡道和一组双向踏台跳跃、补给/失败/F5、透窗碰撞、短按或失去注视会中断按住交互、射线和敌人攻击遮挡。带货与弃货测试从记录匣工位摆位后开始，之后使用实际输入通过。
- **原生连续无射击撤离通过。** [原始日志](route.log)；从自然出生点下生活舱，到钻台取记录，经两段货梯回着陆坪，从坡道进船并封舱。脚本只转相机并发键盘事件，不重放录像、不搬动玩家或直接改任务状态；3,700 个物理步、生命支持 100、发射 0。这不是首玩观察或目标局长测量。
- **4 项原生输入检查通过。** 默认主场景可 WASD 移动，Esc 暂停和恢复，F5 回出生位。[日志](native.log)；另已执行实际 `launch-polar.command`，引擎启动及正常退出。
- **旧内容回归。** `tools/validate.sh`：20 种布局种子、训练场 headless 69 项／原生 75 项、靶板 headless／原生各 24 项均通过；另通过环境模块、风扇和武器回环。旧清剿 49 项任务测试通过。旧训练场在本机仍有历史 BPTC→RGBA8 兼容性警告；本次未替换旧材质或对旧 Benchmark 重新做艺术验收。

开发中不是所有尝试都通过：首轮原生图的连续矮墙挡住了坑底，已换成有真实碰撞的透空栏杆并重拍；测试发现货箱在上船硬点前蹭入支架，已提前上升并加入实体扫掠检查；连续路线的早期驱动撞到支柱、一次丢失窗口按键，分别用可通行路线和按键恢复重跑。

## 画面与性能

[10 张构图帧日志](frames.log)是 1440 × 900 实际游戏相机图；出生帧为原位，其余由验证摆位，另附连续通关截取的封舱与结果帧。WebP 只做编码，未补画或后期上色。白光低角度扫过采掘坡壁，冷灰阴影保留深度；局部中性排气只在钻机附近。轨车和采样臂的琥珀色是预警，不参与雾或全场色调。新网格、表面、天空、功能图标与音频均在运行时由代码构建；无资产生成服务或离线贴图。

| 1600 × 900，不限帧短采样 | 平均 FPS | P95 帧时 |
| --- | ---: | ---: |
| 坑缘与撤离船 | 151.1 | 8.56 ms |
| 钻台与活动轨车 | 143.8 | 8.54 ms |
| 生活舱玻璃与照明 | 153.0 | 8.39 ms |

每处 114 帧，脚本摆动视角；首帧约 759 ms，自实例化开始，不含导入。见[测量原始数据](native.json)。不能外推到其他设备、整个关卡低帧或全局稳定帧率。

**视觉结论：** 地标、段落曝光、真实几何和磨损已做出有统一质感的实时场景；外壳轮廓、室内管线与接触磨损仍有程序化规律，真空远景与近处材质尚未达到照片级。未做玩家首玩、可访问性或跨平台验收；不把技术门禁和截图当作用户美术确认。

## 复现

```sh
./tools/validate_polar.sh --native
QUARANTINE_QA_OUTPUT="$PWD/artifacts/legacy-quarantine" ./tools/validate_quarantine.sh
LUNA_QA_OUTPUT="$PWD/artifacts/legacy-training" KNOCKDOWN_QA_OUTPUT="$PWD/artifacts/legacy-targets" ./tools/validate.sh
```

如在应用目录或 `PATH` 中找不到 Godot，设置 `GODOT_BIN`。验证产物输出到 `artifacts/`，不覆盖旧证据。
