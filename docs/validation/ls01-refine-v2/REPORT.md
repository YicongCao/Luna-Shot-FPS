# ML09 实施与验证报告

平台：macOS / Apple M5 / Godot 4.7.2 Compatibility；Blender 5.2.2 Cycles Metal。全部实机证据由Godot原生窗口捕获。技术检查与本轮结构视觉复查通过，已启用默认 ML09；用户验收待定。

## 结构与材质

以ML06为弹夹结构依据、概念为形状目标，保留ML07涂层/露底/油污体系。`review.html` 提供同镜头ML06/ML07/ML09三列对照及灰模。

- S01：屏左右极点下移至距底20%高度；同形底座/边框与嵌入玻璃，四颗钢色十字螺钉。见`ml09-pbr-screen.png`及侧视。
- S02：枪托采用变截面八角壳体，宽倒角两边都有真实棱线。见`ml09-clay-stock.png`、反侧。
- S03：黑色阶梯插块与白色斜切舌片重新形成错层接口。见`ml09-pbr-joint.png`。
- S04/S05：瞄具外框/孔径均八角，上窄下宽，前后浅侧切；前后各三片装置。见`optic`、`optic-front`、`optic-side`及ADS。
- S06：分段顶盖、浅槽、斜槽、边缘层次、卡扣和端盖恢复，全部随弹夹动画移动。见`magazine`、反侧、掠射光和换弹。
- S07：重做前护罩开窗、上下支撑与六片金属肋、内支撑条及接合套筒。九个未改零件保持原几何/UV。
- S08：两盏近距离Omni保留，加左右两盏青色有阴影Spot，射程0.43m、53°、能量0.20。能量/F9开关同时控制四灯，独立武器世界不会改变环境照明。

## 实施中发现并修正

1. 弹夹端部螺钉不贴面：移到侧面板承托位置。
2. 开放护罩露出旧线圈接合：补真实套筒及内支撑条；保留线圈本体。
3. 附件烘焙未完成就尝试打包：拒绝缺图，加入整批报告完成与源SHA匹配检查；未发布默认资源。
4. 旧QA写死15网格/2灯/旧贴图目录：按版本检查13网格/4灯，并检查实际所选贴图。
5. Spot小阴影偏移导致条纹：偏移调整后保留遮挡，降低能量避免压过材质。
6. 弹夹反侧斜向伪影：定位三角化丢失custom normals；保留逐角法线并重烘焙。修正前平面法线点积最低0.792，修正后源与glTF均0.999977。不能将此缺陷解释为划痕。

失败日志/截图见`rejected/`；废弃大体积烘焙留在Git忽略的`03-bake-rejected`，有效源和最终图版本化。

## 验收边界

数值检查补充视觉复查，不替代视觉。当前枪口/握把等九个保留件仍有旧生成资产的软边；字标字重、磨损艺术布局与概念仍可继续调整。本轮不宣称整枪与概念逐像素一致，也不改写ML07的用户验收状态。

本轮新增付费生成调用：Tripo 0、imagegen 0，复用ML07两张油污/磨损遮罩。

## 补光检查的采样修正

最初护罩采样点在肋片自由边缘（源坐标边界），重烘焙后仅少量像素有变化，未达到门槛。没有降低判定阈值或提高灯光凑数；把点改到明确存在的内支撑表面（Godot坐标`±0.050, 0.016, -0.44`），同样33×33区域、同曝光重新拍摄。两个方向分别约920/886像素产生可测青色增量，遮挡实验超过12万像素变暗。原采样失败结果在`rejected/edge-probe-spill-pixels.json`。

## 最终回归结果

- 几何/高低模cage/UV重叠及间隔/烘焙投射/实际glTF法线与切线：全部通过；9个保留件与环境原资产保持一致。
- 弹量75项通过；原生枪械QA零失败，含命中、换弹、红点渲染和超宽准星。
- 光照13项通过；新增补光开关与实际遮挡像素检查通过。F2总览、F3往返通过。
- 默认ML09、LS01_BASELINE回ML06、LS01_CANDIDATE保留ML07、显式参数覆盖环境变量均通过。
