# ML25 — 暖黄体积雾与原生对照

实施：2026-11-17；验证归档：2026-11-18。范围：独立 Quarantine 关卡和实时 Benchmark；原 Compatibility 训练场、共享环境/枪械资产和 ML24 交互保持。

## 方向与实际变化

用户明确喜欢 ML22 首轮偏黄体积雾的末世氛围。本轮恢复这一美术方向，而不是回退旧 HUD、终端设计或工业结构，也不把偏暖本身视为需要修复的缺陷。

- 默认 `amber`：低角度暖色太阳、灰金色远景、较厚的体积雾和冷色设施光。
- `QUARANTINE_ATMOSPHERE=clear`：沿用 ML24 清淡参数，使用同一套当前几何、材质和交互。
- 太阳角尺寸 0.53°，开启阴影级联混合；不是屏幕模糊滤镜。
- 环境风格写入原生 capture / Benchmark JSON，避免把不同预设的证据混在一起。
- 无新增 Tripo / imagegen 调用。既有光学/磨损素材保留，不将程序天空或调色描述为新 imagegen 产物。

实现：`scripts/quarantine/atmosphere.gd`，由 `world.gd` 在环境初始化时调用；天空着色器新增 `amber_haze`。

## 同机位视觉复查

[原生对照页面](review.html) 提供入口、ADS、终端、供电恢复四个机位的 amber / clear 切换。

- **收益：** 远景形成暖灰金色雾层，工业轮廓与逆光更接近用户喜欢的首轮气氛；蓝色能源和全息面板在暖背景上有明确色彩分离。
- **代价：** 远处结构对比度降低、背光虫体暗部细节减少；并非每个表面都比清淡版更易读。近处准星、敌人发光部位和终端主操作仍可识别。
- **中间修正：** 第一版太阳色与散射色叠加过于橙、饱和度偏高，已收敛到灰金色。`first-amber/` 保留中间版，不冒充最终画面。
- **尚未解决：** T-Bug 的程序化圆润外壳和规则肢体、重复模块、部分高亮边缘仍有明显游戏样板感。暖雾增强气氛，不等于这些结构已达到照片级。

`amber/`、`clear/` 为同机位原生帧；`../quarantine-v1/first-pass/` 为历史方向参照，不是相同资产/UI版本。镜头、敌人和阶段有脚本编排，电击检查图还会固定效果年龄；不是无人干预游玩实录。

## 验证与日志扫描修复

首次完整运行的 JSON 和人工逐日志检查显示：49 项任务、69 项旧训练场、20 种布局种子、6 项原生、23 项反馈、12 项演示、11 项操作衔接检查均无失败。但外层脚本依赖本机不存在的 `rg`，在 `if` 条件中跳过了错误扫描，不能只凭其退出码宣称验证完整通过。

已增加 `tools/quarantine/check_log.sh`，两个验证入口共用系统 `/usr/bin/grep`：错误匹配、文件缺失或读取失败都会令门禁失败，只有“没有匹配项”才通过。用 clean / SCRIPT ERROR / CHECK false / missing 四种输入检查返回码。首次运行保留于 `first-validation/` 和 `first-validation.log`；修正后的完整重跑输出写入 `validation/`，不覆盖历史。

修复扫描后的首次重跑在全息锁定检查处失败：测试用35个渲染帧等待淡入，而运行时可读状态按0.1秒物理采样、透明度按秒变化；帧率较高时未必等待足够时间。失败图已经显示锁定面板，但检查时刻未满足可读门槛。保留证据于 `timing-failure/`；测试改为等待1秒，不改变运行时淡入、交互门禁或检查断言。

### 性能（不混用两次运行）

最终无截图结果：[`validation/performance/result.json`](validation/performance/result.json)。macOS / Apple M6 (Apple9) / Godot 4.7.2 / Forward+ Metal，1920×810实际像素、2133×900逻辑画布、VSync请求关闭。预热4秒，测量47.513563秒、6336帧；平均 **133.351 FPS**，P95 **8.952 ms**，P99 **9.605 ms**。

首次相同暖雾运行的无截图结果仍保留于 `first-validation/performance/result.json`：47.507688秒、2848帧，平均59.948 FPS、P95 17.401 ms、P99 18.071 ms。两次虽都记录 VSync=0，但运行/窗口合成状态未受控，帧率差异原因尚未定位。本轮未做能解释两倍帧率的运行时性能优化，**不能把133 FPS称为相对60 FPS的优化成果，也不承诺稳定维持该帧率**。不与旧平台、另一路线或带截图的结果直接比较。

## 复现

```sh
./launch-benchmark.command
./launch-quarantine.command
QUARANTINE_ATMOSPHERE=clear ./launch-benchmark.command
QUARANTINE_BENCHMARK_QA_ROOT=artifacts/ml25-recheck ./tools/validate_quarantine_benchmark.sh
```

Benchmark 为约52秒实时编排：9发真实射击击杀3只，另外5只切镜清除；真实 E 输入和胶囊撤离。结束后 R 重播 / Enter 正常实玩 / Esc 退出。正式性能使用实际启动脚本、不写截图，排除前4秒预热；带截图的演示只作功能/视觉证据，`menu-test/` 只测试菜单切换，不是性能样本。

## 验收边界

这是暖黄方向的实际实现与原生证据，不是用户已验收，也不是“3A照片级”完成证明。当前只验证 macOS / Apple M6 / Godot 4.7.2 / Forward+ Metal。尚未完成多平台、手柄、新手可用性或长时间稳定性验证。退出时仍出现7个 Texture RID 警告，原因未定位；既不能宣称资源完全释放，也不能仅凭退出警告断言持续运行内存泄漏。
