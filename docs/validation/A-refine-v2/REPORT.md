2026-11-15。按环境概念设计板完成 A 样板；只更新 A 的视觉资源和其小型状态条材质，其他五件模块、关卡布局、碰撞与接口不变。没有调用 Tripo，新增 Tripo 费用为 0。

## 实现

- 六块独立顶盖，明确板缝、密封垫层、边缘倒角和提手区域；24 个顶盖紧固件及浅压纹从高模投射。
- 三扇前检修门，每扇两处铰链与两处锁扣；独立门封、铭牌区域和中央诊断条。背面增加两块可拆检修盖。
- 侧面采用实际凹入的接口舱，包含三组安装板、密封圈、橙色键位环、金属插头和橡胶应力释放护套。
- 三根弯曲线缆带固定夹，末端进入底座线槽；全部收在原外包络内，不侵入通行支路。
- 四组安装脚、叉装空隙、锚固底板和滑橇边梁；涂层、深色金属、银色合金、橡胶、警示色及小型青色诊断条分开表达。

本轮是可复现的本地重构式精修，不是再次付费生成。既有 Tripo A 源文件保留在 pipeline-v1，新版使用脚本定义的装配结构与分别构建的高低模。

## 预算与管线

新版高模 65,252 三角，包含高模专用紧固件和浅压纹。总计减少 2,603 三角/实例，40 个实例减少 104,120 三角。规划占地内实际外包络仍不超过原 3.8×3.8×1.2 m；详见 [asset-audit.json](asset-audit.json)。

真实 Cycles selected-to-active：2K、16 samples、8 px 外扩、25 mm 射线外移和 65 mm 最大距离。输出 NormalGL、AO、Roughness，以及独立投射的 BaseColor / Metallic / Emission，AO 合并到 ORM 红通道。最终单网格单材质；可编辑高低模和烘焙配对文件保留。

UV 越界 0、退化 UV 三角 0、严格内部重叠像素 0；2K 图集覆盖率 56.55%；非流形边 0。低模生成时清除了倒角/三角化产生的零面积三角，然后重新展开并烘焙。

材质处理中发现 DIFFUSE color bake 会把金属的底色按漫反射比例压暗；最终 BaseColor 改由高模材质的纯颜色 EMIT 通道投射，避免将光照或金属衰减烘进底色。NormalGL 和 AO 仍来自真实几何投射。

## Godot 验证

- 旧版与新版均使用 Godot 4.7.2 / macOS / Apple M5 / Compatibility。四侧、顶部、法线关闭与恒定材质对照均来自原生窗口；离线结构预览仅保留在源目录。
- 独立观察场景提供到正面板 3 / 10 / 20 m 的相同视距；关卡截图展示近距离玩家视角、设备阵列和总览。近景可读出门锁、接头和线缆，中远景以分块与轮廓为主。
- 20 个种子确定性与布局检查、188 项模块检查通过。
- 69 项无界面训练检查、81 项原生检查通过，原生真实玩家胶囊运行 148.558 秒，包含外围、支路、高架、桥下、五靶、重置和超宽窗口。该回归验证新版几何；此后只修正了 BaseColor 投射通道并重新拍摄最终实机对照。
- 最终枪械 19 项无界面、29 项原生检查与材料对照全部通过，结果保存在 rifle/，包括红点、换弹和 F3 往返。

当前是可以作为 B1/B2/C/D/E 后续精修参照的装配与材质样板。外壳背侧保留安静表面，铭牌区域尚未扩成详细文字贴花；未新增开门交互、设备内部或可插拔线缆玩法。没有把概念图中越界的地面线缆照搬进关卡。
