# ML26 — T-Bug 机械结构精修

日期：2026-11-18。平台：macOS / Godot 4.7.2 / Forward+ Metal。

## 目标与保留项

暖雾不能替代模型质量。本轮针对近景害虫由球体、细杆组成的样板感进行程序几何精修，不改变环境光照来遮掩模型问题。

**待修缺陷：** 球状装甲没有板厚/接缝、关节和脚缺乏装配关系、背部发光体像裸露球体、金属高光过于均一。

**不可损失：** 六足/双触角、三对可独立损伤的装甲、橙色敌人识别光、现有大致体积、三发击杀、原胶囊和移动/近战遮挡契约。HUD、全息终端、ML25暖雾、原训练场和共享资产不变。

## 实现

- `scripts/quarantine/bug_visual.gd`：代码构建的切角装甲、实体坡面倒角、密封底盘、传感器框、24枚固定螺栓及槽口、装甲通风条、旋转关节端盖、执行器套筒/活塞杆、踝轴和双层脚垫。
- 九格背部发光件置于有实体壳体的脊槽，触角端点装入护套；并非新增imagegen产品。
- 六片受损装甲和六个动画腿根保持独立；只合并相同父节点下的刚性附件，伤害时附件随装甲偏移。
- 材质复用 ML23 `industrial.gdshader` 与历史 `wear_mask.png`，区分涂层、橡胶与机加工金属。UV按米构建，微表面仍是解析着色，不声称高模投射烘焙。
- `bug_damage.gd` 支持涂层ShaderMaterial的独立损伤副本；不增加伤害、追踪或电弧预算。新增真实命中检查，保证未被击中的另一只害虫不会随共享材质一起变黑。
- 默认 refined；`QUARANTINE_BUG_STYLE=baseline` 查看旧版。capture / Benchmark JSON记录实际bug_style。

无新增Tripo、混元或imagegen调用；没有改动任何既有GLB/UV/烘焙法线，因此没有冒充新的资产烘焙产物。

## 几何与原生视觉复查

[对照页面](review.html) 包含左右前侧、背面、正常第一人称尺寸。灰模关闭材质/自发光差异，使用一致中性灰、43°诊断镜头及随相机移动的2.5能量Omni补光；彩色图不加这盏检查灯。第一人称尺寸镜头78°。这是原生关卡内摆拍，不是正常游玩自动出现的镜头。

### 收益

- 球体拼接改为可读的装甲板厚、切角和装配缝；实体几何在灰模下也成立。
- 腿部有关节、驱动杆、踝轴和脚垫，不只靠材质画机械细节。
- 保留橙色识别光，但光源有实体承载；近景螺栓/通风条和不同材料的反射有分层。

### 损失与开放问题

- 外壳更硬朗，牺牲部分旧版圆润的昆虫轮廓；体积/密度略增加，不是零代价的全面升级。
- 阴影侧仍偏暗，材料细节并非在所有角度都显著；发光脊线近景仍有较亮的Bloom。
- 腿仍沿用原动画根节点的摆动，没有接地IK或物理执行器模拟；近景不能称为真实机械运动仿真。
- 不把“多了螺丝/面数/通过验证”当成照片级成功；用户视觉验收仍待定。

### 实际发现并修复的问题

1. 首轮诊断FOV被玩家脚本插值覆盖，近景不够近。冻结诊断玩家的process，增加实际43°FOV断言；旧图保存在 `first-camera/`。
2. 刚性附件合并时混用了有索引圆柱与无索引倒角盒体，部分脚垫和发光件被丢弃。左右侧实拍暴露问题，而初期仅检查装甲面朝向未能覆盖。合并前统一为有索引输入，缓存转换结果，并检查输出三角形总数等于输入总和；错误中间图在 `before-index-fix/`。
3. 补踝轴连接下肢与脚垫。最终几何/材质证据位于 `final/`，不要用目录根部的中间图代替。

外表面法线与顺时针面绕序均检查；左右侧开启正常背面剔除的灰模已实际查看，不仅以面数/体积代替视觉检查。

## 复现

```sh
./launch-benchmark.command
QUARANTINE_BUG_STYLE=baseline ./launch-benchmark.command
QUARANTINE_BENCHMARK_QA_ROOT=artifacts/ml26-recheck ./tools/validate_quarantine_benchmark.sh
QUARANTINE_BUG_STYLE=refined BUG_REVIEW_GRAY=1 BUG_VISUAL_OUTPUT=artifacts/ml26-gray \
  "$HOME/Applications/Godot.app/Contents/MacOS/Godot" --path . --rendering-method forward_plus \
  --resolution 1920x810 --script tools/quarantine/test_bug_visual.gd -- --quarantine-qa
```

Benchmark仍是编排镜头，9发真实射击杀3只、其余5只切镜清除、真实E与胶囊撤离，不是无人干预通关。灰模补光、诊断镜头和固定电击年龄只用于证据工具，未加入正常关卡。Metal退出7个Texture RID警告继续保留为开放项。
