材料检查：游戏中按 **F3**，或运行项目根目录 `launch-weapon-lab.command`。鼠标拖动旋转，滚轮缩放，1 正常 PBR、2 关闭烘焙法线、3 统一金属度/粗糙度、4 灰模，L 切换中性/暖侧光/冷逆光，F3 返回训练场。

红点是瞄具内部 3D 平面的自发光软边着色器，带角度衰减和深度遮挡；非屏幕固定十字，也不依赖全局 bloom。开镜隐藏 HUD 十字，屏幕中心射线用于命中。它是游戏视觉实现，不是物理光学准直模拟。无手臂与完整换弹角色动画，能源匣作为两部件整体移动。

## 模型与贴图

| 项目 | 实际产物 |
|---|---|
| 高模 | 1,934,277 三角面，17 个有效部件；移除 1 个孤立微小碎片 |
| 游戏低模 | 19,658 三角面，17 个部件，单套共享材质 |
| 单位/朝向 | 总长 0.905 m；Blender +Y 前方，Godot −Z 前方；应用单位和变换 |
| 贴图 | 2048² BaseColor / NormalGL / ORM / Emission |
| 颜色空间 | BaseColor、Emission 按 sRGB 编码；NormalGL、ORM 是线性数据 |
| ORM | R=真实烘焙 AO，G=粗糙度，B=金属度 |
| 运行时资源 | 几何 GLB 约 626 KiB，几何与四张 PNG 合计约 6.2 MiB（磁盘大小，非显存估计） |
| 瞄准轴 | 游戏模型 Y=0.178 m；独立枪械视口，开镜光轴对准中心 |

高模由 Tripo 的无材质生成任务提供真实几何细节，本地进行定向、缩放、焊接、法线修复和语义命名；没有靠细分低模伪造高模。原始 B0 白模先于本轮存在；`00-whitebox` 的 B1 是高模检查后更新光轴/能源匣位置的控制代理，**不是声称 Tripo 从 B1 直接雕刻出了 H1**。

Tripo 返回的 PBR UV 与本地低模 UV 最大差约 2.98e−8，没有发生有效布局变化。最终仍通过三角形对应写入固定低模 UV，全部三角形对应成功。Tripo 生成的法线保留在原始输出中，但最终运行时 NormalGL 来自 Blender 高低模烘焙，文件哈希与原烘焙一致。

## 烘焙与材料验证

Cycles CPU，17 组同名高低模匹配，selected-to-active，切线空间 +X/+Y/+Z，2048²，16 px 外扩，射线起始外移 6 mm、最大距离 18 mm；没有独立 cage 网格。每组只启用对应高模投射，减少临近零件误投射。设置、每组投射距离统计和日志均保留。

覆盖 UV 的 943,028 像素中，法线没有全黑像素；法线向量长度 P01/P99 为 0.996/1.004。该统计排除显著空图或编码损坏，不能证明每一处投射都没有瑕疵。AO 黑像素约 4.24%，最终 ORM 将 AO 下限限制为 0.15，避免黑死。

Tripo 原始 PBR 把部分握把涂白、枪口涂橙、能源匣涂暗，并有不可靠字符。最终按语义部件修订颜色、金属度和粗糙度，保留生成材质的低对比细微变化，增加三段青色发光带。低对比处理抑制了生成字符颜色，但几何本身仍有模糊刻字。

| 表面 | 平均粗糙度 | 金属度 | 实机观察 |
|---|---:|---:|---|
| 陶瓷涂层外壳 | 0.442 | 0 | 较宽的柔和反光，表面明暗随灯光改变 |
| 橙色涂层/能源匣 | 0.352 | 0 | 比橡胶亮，保持有色绝缘涂层表现 |
| 暴露金属骨架 | 0.268 | 0.95 | 有色环境反射及更集中的高光 |
| 橡胶握把/托底 | 0.827 | 0 | 高光弱、较哑光 |
| 青色状态带 | 0.222 | 0.10 | 局部发光，不把整把枪染亮 |

在固定相机的枪械区域比较实际截图：关闭法线后 52.6% 像素发生超过 2% 的 RGB 平均变化；统一材质响应后为 47.6%。暖/冷灯光亦产生明显变化。这是**开关确实影响画面**的证据，不是画质评分。数值、方法见 `render-comparison.json`；可在交互页逐张查看。

开镜红点中心投影误差 <0.001 px；普通与 1600×700 超宽窗口均通过中心像素检查。关闭两个枪械方向光后红点仍可见。

本轮原生训练场回归约 48 秒，枪械专项约 6 秒。帧间隔 P95 分别约 8.3 ms、10.4 ms；这是本机短时自动测试记录，包含窗口渲染，不能当作十分钟稳定性或其它平台性能验收。无窗口 fixed-fps 的帧间隔不用于性能结论。

运行 `tools/validate.sh` 复测训练场；`tools/validate_rifle.sh` 复测枪械与材质，并生成实际截图和像素比较。后者需要本机 Godot，以及 uv 的 numpy / Pillow 分析依赖。

## 已知质量限制

- 自动减面网格仍有局部折面、凹痕和不规则接缝，金属强反射会放大这些问题；近景刻字不清晰。尚未进行逐面手工重拓扑与硬表面重建。
- 低模审计有 1,752 条边界边和 74 条非边界非流形边，无退化三角面；它是视觉道具，不是封闭可制造实体。不能把减面产物称为手工干净拓扑。
- UV 利用率约 22.48%；2048² 栅格审计发现 202 个内部重叠采样（占整张图 0.0048%、覆盖区约 0.0214%）。未发现越界，残余微小重叠和碎 UV 岛仍应在下一轮精修时整理。
- 红点有软边光效；当前 Compatibility 管线未用全局辉光。材料实验室与独立枪械视口采用受控环境反射，训练场环境仍为白模，不能据此推断最终月面场景整体光照。

本轮可作为下一轮人工审美选择和局部精修的可编辑基线；不宣称达到概念图的某个百分比。
