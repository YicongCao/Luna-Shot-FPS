# ML22 · SELENE / QUARANTINE

2026-11-17。**独立可玩任务与电影化视觉第一轮完成；3A照片级目标尚未达到，用户视觉验收 pending。**

## 如何运行

- 项目根目录双击 `launch-quarantine.command`，或 `./tools/launch_game.sh quarantine`。
- Godot 4.7.2，独立启用 Forward+，窗口1920×810；原 `launch.command` / project.godot 仍是 Compatibility 固定靶训练场。
- 本机 Godot 从官方4.7.2稳定版下载，安装至 `~/Applications/Godot.app`，不将引擎二进制提交仓库。
- WASD移动，Shift冲刺，Space跳跃，鼠标转向，左键开火，右键ADS，R换弹。清理8只T-Bug后去北侧终端，距离3m内按住E 3秒，再回南侧绿色圆环撤离。ESC暂停；F5在运行/暂停/失败/成功均可重新部署。
- F7开关环境与枪械Bloom，F8开关光学flare，F10可选黑边（默认不裁剪可玩视野）。
- `QUARANTINE_COMPAT=1 ./launch-quarantine.command` 是兼容渲染回退，不含SSR/SSIL/体积雾等Forward+效果；本报告高质量原生证据不是该回退画面。

## 已实现

1. **玩法闭环**：8只程序化机械害虫，三发击杀，六足步态、巡逻/局部射线避障、视线内追击、近战冷却与高差限制。生命值100，失败/重开，清剿→终端→撤离状态门禁。一次死亡只计分一次，尸体熄灭且不碰撞。
2. **独立场景与保护**：实例化原训练场副本并替换玩法，不改原训练场/布局/生成器/枪械资产；副本B11从(6,0,22)移至(30,0,6)，打开出生视线。保留原59个主题实例，在基础设施层新增批处理钢架、檩条、管路、围界、终端和撤离门框。场外月面使用连续程序高度场与既有月壤纹理，不是远景概念图。
3. **照明**：低角度暖色太阳、冷色环境/局部灯池、阴影、反射探针、SSAO、SSIL、SSR、TAA和克制体积雾。枪械仍在独立透明视口，使用已验证高亮提取/模糊合成，不重新启用裁alpha的原生武器Glow；枪械主光随场景日光遮挡变暗。
4. **光学与场面**：复用既有imagegen streak/halo，仅对屏内无遮挡源产生anamorphic flare；开镜降低强度。激活终端后电网转绿，中央能源柱、粒子与地面扩散环启动，指向撤离。
5. **射击增强**：保留ML13电弧及其伤害/碰撞，在真实撞点追加12槽、最多264粒子的短寿命火花/碎片；加入纯代码合成放电低频、工厂环境音和克制警报。无新增跟踪伤害或相机自动瞄准。
6. **战斗机HUD**：右键渐入航向带、俯仰刻度、实时测距、弹量刻度、至多3个可见敌人括号。LOS遮挡，不透墙。常态任务/生命/弹量与可点击暂停、重新部署按钮。小字最低13屏幕像素。

## 原生证据

[图文与视频页面](review.html)。`native/*.png` 全部为 Godot 原生视口，1920×810；含出生、ADS、放电、桥面、终端、能源恢复、撤离和成功。

- 固定相机图冻结敌人以方便比较；03为实际开火效果的12ms确定性采样，不是手绘叠加。其余靶清理与终端阶段可由验证脚本直接推进，不能冒充完整人工通关。
- `showcase.mp4` 为Godot MovieWriter原生逐帧输出后H.264/AAC转码，脚本化机位、预置敌人，展示真实射击、按E、恢复供电和撤离。它是演示短片，不是玩家无干预通关，也不以录制60fps说明实时性能。
- `first-pass` 保留初次过黄雾、近景遮挡与过小HUD的失败样板；`second-pass` 保留中间版。最终减少雾、移动副本B11、增加HUD对比、补齐檩条和连续月面。色调更清晰，但部分新基础结构仍偏程序原型。

- `training-regression.log`：**69项旧训练场headless检查通过**，涵盖环路、两侧支路/高架、桥下、护栏、边界、五靶射击、换弹、暂停/复位。未重复全部旧枪械材质专项或完整 `tools/validate.sh` 原生套件；本次未改既有枪械/贴图。
- `training-regression/generation.json`：20种子确定性与非法布局拒绝通过。输出重定向至本目录，不覆盖历史证据。

- HUD/FX隔离引擎冒烟：遮挡下不画目标括号，30发效果节点数量不增长，合成WAV非零且不削波，RESUME/REDEPLOY回调通过。headless不启动不可听音频，原生保留声音。

## 实时性能

`performance/native.json`：预热5秒后60秒，1920×810，Forward+；真实胶囊沿中央、维修支路、桥面和外围行走，转动观察、周期ADS和射击。为避免死亡中断，仅此基准脚本持续补充生命，不是正常游戏规则。

- 平均 **141.58 fps**；中位帧时 **7.038 ms**；P95 **8.397 ms**；P99 **8.869 ms**。
- 累计行走 **261.20 m**、到达11个路径点、最高胶囊脚底 **2.410 m**；119次开火请求（包含换弹阶段，并非119个实际命中）。
- 末帧1,133 draw calls / 1,926,132图元计数 / 约1.69 GiB引擎视频内存计数。包括多遍阴影/后处理，不等于独立模型三角数或操作系统GPU内存测量。
- 这是本机60秒路线结果，不代表跨平台保证、4K性能、长时稳定性或所有能源特效峰值。能源恢复另有原生截图/视频，不混作基准持续负载。

## 保留的限制与未达到项

- **没有达到可诚实称为3A照片级的整体画质。** 既有设备资产仍是当前低模/PBR，程序甲虫尚无独立高模烘焙，围界/终端/顶棚的几何、磨损与叙事细节仍较简单；当前是可玩的电影化方向样板。
- 月面远景和天空星球为程序艺术表达，非真实地理/天体照片；体积尘光不是月球真空物理模拟。
- T-Bug局部避障没有全局导航，复杂凹角/长时拥挤还需游玩调校；没有新增波次、存档、难度菜单、破坏地形或多人。
- 原生Forward+/Metal进程退出仍记录 **7个Texture RID释放警告**，见native/performance/showcase日志。没有将警告删除或报告成零问题；尚未定位其引擎/视口资源来源，不能据此断言运行中泄漏或无泄漏。
- 未做独立打包分发或其他机器实测；Compatibility回退未作为照片级画质验收。声音完成合成/播放与数值检查，主观听感仍需用户评价。
- 用户美术验收pending，不更改ML21或旧环境的历史验收结论。

## 复现

```sh

./tools/validate_quarantine.sh --native        # 追加Forward+原生图
```

脚本默认查找Godot应用；可设置GODOT_BIN。录制另需ffmpeg。原始AVI仅在artifacts，交付MP4/PNG按Git LFS管理。
