# 白模检查记录 · 2026-11-15

平台：macOS、Apple M5，Godot 4.7.2-stable (official)，OpenGL/Metal Compatibility。当前只检查白模功能与画面构图，没有把概念图作为实机成果。

- 无窗口物理检查 **32 项通过 / 0 失败**；fixed-fps 加速执行，不用于测性能。
- 原生窗口 **40 项通过 / 0 失败**，包含 7 张真实渲染截图。持续 48.2 秒；包含停留、走动、模式切换与截图，不是长时间稳定性测试。
- Blender → GLB → Godot 的 **22 个分件/挂点比对通过**；逐件比较名称、位置和包络，容差 0.1 mm。
- 原生检查帧间隔 P95 约 16.36 ms，仅为该次短时运行观察；不作为锁定 60 FPS 的验收。

## 已检内容

完整外侧/中央环路、飞船西侧 3.5 m 通道、坡道两侧路径、东西坡道双向通行、平台横向连接和 2.4 m 高度。四侧围墙在跳跃时阻挡胶囊；出生点落地正确。

靶命中与计数、射击冷却、空弹匣锁定、换弹期间禁射与完成补满、建筑遮挡射线、暂停冻结动作与换弹、重置弹匣/位置/统计/相机模式、开镜前后挂点与中心轴对齐。

修正并重测：坡道初版旋转方向错误；停机坪 12 cm 边缘改为齐平；自动实走路线避开实际掩体/靶；HUD 底部锚点；武器初始占屏过大；窗口宽屏适配从保持原比例改为 expand。环路通过指最终列出的可通行路线，不表示玩家可以直穿所有物体。
