# ML27 — 特写构图、原生景深与实体检修灯

日期：2026-11-18。

## 目标与范围

ML26增加了机械结构，但原Benchmark特写处于背光侧，主体与暗地面重叠。本轮针对“镜头是否把已有结构呈现出来”，不是再次提高雾量/Bloom，也不把景深功能本身当成照片级证明。

- 保留用户喜欢的暖黄体积雾、太阳光、环境色与整体曝光。
- 不改变原Compatibility训练场、共享枪械/设施资源、敌人伤害和任务流程。
- 景深只用于Benchmark约19–24秒的T-Bug特写；实际战斗、ADS、终端、撤离和进入正常游玩均恢复原相机属性。
- 新增一盏真正挂在既有屋架下的检修灯，正常Quarantine与Benchmark共用，不是只在截图中出现的补光，也不跟随相机/敌人。

## 三个可分离的变化

### 构图

`benchmark.gd`特写改为面部/侧装甲三分之四视角，FOV46°，为最近的脚保留画面边距。其他两只冻结害虫在特写期间移到镜头外，进入真实射击阶段前恢复原站位，避免近景相机穿进另一只害虫；这仍属于已披露的脚本化镜头/敌人编排，不是正常AI游玩。

开场设施总览和能源恢复镜头保持，避免所有镜头都变成丢失空间尺度的特写。

### 原生景深

`scripts/quarantine/benchmark_lens.gd`使用Godot CameraAttributesPractical，自动曝光关闭，曝光倍率1.0。按实际相机空间目标深度更新焦距；远景模糊从目标之后0.65m开始、过渡4m、强度0.12，近景模糊关闭。它是引擎基于深度的景深近似，不是后贴全屏高斯模糊，也不宣称是完整物理镜头模拟。

切镜恢复原CameraAttributes；结束菜单进入正常关卡也检查属性没有残留。HUD和枪械瞄准不承担景深模糊。

### 实体检修灯

`scripts/quarantine/service_lighting.gd`在现有z=0屋架下的(-3,10.5,0)安装一个支架、灯壳和扩散面。灯头朝向(1,0.45,16)，实际Spot位于扩散面前方，避免灯壳自遮挡。

一盏Spot：能量24（引擎参数，不当作实测流明）、颜色(0.78,0.83,0.88)、范围26m、半角26°、光源尺寸0.6、软阴影、体积雾贡献0。它只恢复局部装甲/腿的明暗分离，不整体提亮天空或暖雾。没有虚构额外镜头光晕源。

## 原生对照与实际复查

[对照页面](review.html)提供五组21秒定格原生帧，`published/`为最终证据：

1. `baseline`：旧机位，景深/检修灯关闭。
2. `reframed`：新机位，景深/检修灯关闭。
3. `focused`：新机位+景深，检修灯关闭。
4. `lit-no-dof`：新机位+检修灯，景深关闭，单独检查照明收益。
5. `final`：新机位+景深+检修灯。

这是直接运行引擎、固定在编排21秒处的诊断帧，不是离线渲染或完整通关视频；完整实时演示另行运行。

### 独立图片复查后的修正

初版独立复查认为：景深仅温和改善注意力分配，并未解决暗部；新机位裁到最近的脚，旧机位反而更有设施尺度。这些意见不是用户美术验收。

据此扩大构图余量、保留原宽镜头，加入实体局部照明。第二版发现另一只编排敌人挡住前景，以及远距离Spot初始能量不足；调整了特写期站位和灯光参数。`first-pass/`、`second-pass/`保留中间证据，目录根部三组图是补光修正后的中间采样，最终以`published/`为准。

### 收益与损失

- **收益：** 主体完整进入画面；面部、装甲块和腿从暗背景中分离；背景线条/设备不再与主体等清晰度争夺注意力。
- **代价：** 特写损失部分环境尺度/细节；局部检修灯增加一盏有阴影Spot的开销，近处阴影更偏中性冷色。未改变全场暖色方向。
- **开放差距：** 造型和运动仍有程序样板感，模块重复与远景棱角、部分细密阴影纹理仍未解决。新镜头不等于整个关卡已达到照片级；不能凭技术门禁或本轮独立复查声称用户已验收。

本机正式性能：Godot4.7.2 / macOS / Apple M6 (Apple9) / Forward+ Metal，1920×810实际像素、2133×900逻辑画布、VSync请求关闭。预热4秒，测量47.509685秒/6205帧；平均 **130.605 FPS**，P95 **9.421 ms**，P99 **9.920 ms**。原始数据见`validation/performance/result.json`，确认`closeup_dof=true`、`closeup_framing=lit-closeup`、`inspection_light=true`。这是本次短程条件下的结果，不是跨平台/长期稳定性能承诺；不将其与窗口状态未受控的约60 FPS结果作直接优化比较。

最终特写、正常ADS及设施总览均实际查看：灯具在屋架下可见，ADS没有景深模糊，暖黄远景保留。最终日志未出现脚本/解析错误或失败检查；仍有7个Texture RID退出警告，未宣称完成资源泄漏修复。
