# T 系列靶击倒验证

2026-11-15，Godot 4.7.2，macOS 原生窗口及无窗口各 24/24 项通过。

T01–T05 命中一次后，靶牌、编号与支架以底部为支点，在 0.42 秒内向后倒下。首次命中立即移除靶碰撞层；重复调用命中或射击原位置不重复计分。倒下后保持倒地，F5 统一复位。

验证包含五个靶的真实射线命中、倒地角度、重复命中拒绝、原位置不重复计分、全体复位、暂停冻结动画、动画中途重置不会继续倒下，以及复位后再次接受命中。
