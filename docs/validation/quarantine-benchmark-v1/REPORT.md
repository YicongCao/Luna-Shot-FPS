# ML24 — 实机 Benchmark、图标导航与终端交互

日期：2026-11-17。环境：macOS / Apple M6 (Apple9) / Godot 4.7.2 / Metal Forward+。

## 一键运行

`/Volumes/INTEL/Projects/Luna-Shot-FPS/launch-benchmark.command`

约 52 秒，4 秒预热，然后依次展示入口、工业立面、T-Bug、三组真实射击、终端交互、上电和撤离。默认 1920×810；可传入 `--fullscreen`。没有 VideoStreamPlayer、MP4 播放、MovieWriter 或固定帧率替代真实渲染。

结束后可按 **R 重播、Enter 进入可玩关卡、Esc 退出**，也有对应按钮。Esc 在演示途中同样退出。正常玩家运行不自动关闭；`--benchmark-qa` 仅供验证完成后自动退出。

结果默认写入 Godot `user://benchmarks/<本机时间>/result.json`，绝对路径输出在启动终端中。可用 `QUARANTINE_BENCHMARK_OUTPUT` 指定位置。

### 真实性边界

- 镜头和敌人站位经过编排；三只敌人由九次真实 `player.fire()` 命中击杀。
- 剩余五只在镜头切换时直接清除，以压缩展示时长。终端通过真实按住 E 输入，撤离通过实际胶囊移动完成。
- 演示补满生命；不是无人干预通关，不作为完整 AI 行为或关卡难度证据。
- 功能为实时引擎内演示，不把截图或离线渲染冒充游戏画面。

## HUD 与终端重构

见 [UX 复查](UX-REVIEW.md)。任务条统一为害虫 `n/8`、终端 `0/1`、撤离 `0/1`，不显示百分比。阶段图标、弹量、生命和必要按键取代品牌口号/英文解释。

终端和撤离点具备屏内定位与离屏方向提示，目标在背后时指向下侧，避免仰视终端后将身后撤离目标误指向天空。只标记静态任务位置；敌人括号继续受实际 LOS 约束。

终端现在只有一个设备投射的全息信息面：

1. 未清剿：害虫图标、数量、锁定状态。
2. 可操作：电源图标、`0/1`、E 按住 3 秒；秒数和填充反馈不表示任务百分比。
3. 已完成：出口图标、必要动作“前往撤离点”和距离。

7m 内无遮挡、位于设备前侧时显示面板；近距离面板可读时，HUD 不重复叠加 E 提示。实际交互另要求 3m 内、看向设备、处于前侧且物理 LOS 无遮挡。松手、转身、离开或遮挡中断连续按住。终端完成数量以独立 `terminal_completed` 保存，避免失败状态将已完成项目误显示成未完成。

面板是 640×384 SubViewport → 世界空间 QuadMesh，具有实体投射槽、连接线和边框；必要功能文字有承载面，不是裸 Label3D。建筑能源标识改为闪电而非另一个电源按钮。

## T-Bug 电击表现

真实命中后的回调才触发：壳面短路电弧、核心闪断、肢体抽动、命中附近装甲变暗；致命击中后装甲轻微偏移、断电侧翻，残余电弧在 2.2 秒内结束。保留原三发击杀、伤害和遮挡契约。

每只最多 4×6 段电弧，只有一个 ImmediateMesh，不逐发增加节点；弧段检查建筑遮挡。已有火花与小碎屑池仍复用。短路声为本地合成，非新 imagegen 资源。

这不是完整物理断裂或拟真材料损伤模拟，没有宣称熔穿、真实装甲碎裂或烟尘物理。

## 验证

入口：`tools/validate_quarantine_benchmark.sh`，支持 `QUARANTINE_BENCHMARK_QA_ROOT` 重定向新阶段证据。

- 任务逻辑/物理：**49 项，0 失败**，新增前向注视、墙体遮挡、背侧拒绝及转身中断。
- 原训练场 headless：**69 项，0 失败**；20 种子布局回归通过。
- 原生任务 capture：**6 项，0 失败**。
- 完整实时演示：**12 项，0 失败**，含九次真实射击、三只击杀、E 激活、胶囊撤离。
- 重播/进入实玩/正常移动/暂停恢复：**11 项，0 失败**。实际注入 R、Enter、Esc 按键事件。
- 定位、电击与全息面板专项：**23 项，0 失败**，结果保存在 `feedback/checks.json`；包含真实命中、墙体拦截、暂停、效果寿命、固定节点预算、屏内/离屏/背后投影、全息锁定/可用/中断/完成状态。

`feedback/02-hit-inspection.png` 固定电击表现年龄 90ms；死亡残余图固定 380ms，均为原生场景诊断图，不能描述成自由游玩抓拍。`native/` 是完整实时演示的阶段画面。截图采集运行会造成额外开销，性能另跑无截图版本。

### 无截图 Benchmark 性能

`performance/result.json`：物理输出 **1920×810**，逻辑 UI 画布 2133×900，两者明确分开；VSync 请求关闭。预热 4 秒后采样 47.51 秒、2,849 帧：平均 **59.97 FPS**，P95 **17.430 ms**，P99 **18.149 ms**。

这是这条实机演示序列的本机窗口结果，不是独立 60 秒行走路线成绩，亦不宣称测得 GPU 峰值能力。没有跨平台/分辨率排名。

## 已修复的问题与保留历史

- 第一轮将逻辑画布大小误写成输出分辨率；改为 viewport 实际像素，原记录留在 `first-pass/`。

- `before-hologram/` 保留先前图标版及双图标问题，作为交互重构对照，不是当前版本。
- 原 ML22 / ML23 历史证据、训练场、布局与共享模型/贴图未被覆盖。
