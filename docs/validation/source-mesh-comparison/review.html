枪械与 B2：原始网格 → 本地高模／低模 → PBR 原始贴图

灰模图全部由实际源文件在 Blender Workbench 离线渲染，非游戏实机、非概念图。统一灰色材质、灯光、相机；关闭贴图／烘焙法线和 cavity，观察几何自身。原始网格只做旋转、等比尺寸归一及平移，无镜像或按轴拉伸。图中面数是本次显示的网格，不包含游戏动态附件。

枪械必须分两条历史：当前默认ML06来自Tripo高模的保留/修整；ML07局部重建方案已回滚。B2当前是ML15本地重建。枪械图只比较主体，统一排除后加工业附件；ML07未重建部件在高/低两图中用相同保留低模作装配参照。PBR页另列主体和附件，避免把一张atlas当成整枪。
