# ML36 · 南极采冰站光照精修

2026-11-23 · Godot 4.7.2 stable / macOS / Apple M6 (Apple9) / Metal Forward+。

[同机位原生对照](review.html) · [ML35 首版证据](../polar-extraction-v1/REPORT.md)

## 实现与取舍

- **接触层次。** 沿用原生 SSAO，不叠新一遍屏幕 AO。半径从 0.84 m 收至 0.70 m，提高强度与近处细节，优先拉开柜底、设备支脚、墙角和窄接缝，不把整个阴影区再压黑。这是屏幕空间效果，不是离线 AO 烘焙，屏外遮挡仍不参与。
- **局部体积光。** 将一盏既有钻台 Spot 挂到下层平台底下，让它确实穿过排气，不额外加一盏全场灯。固定有阴影的灯照亮 `exhaust.gdshader` 生成的渐散排气；密度只在出口后约 5.8 m 的包围区内，体积不自发光，全场雾密度仍是 0。将体积采样范围从 52 m 收到 38 m，减少对远处真空的采样覆盖；排气不是流体模拟，也不挡路或造成伤害。
- **灯面与操作台。** 实际灯罩的 HDR 发光驱动两级原生 Glow；不对整张亮面加泛白 Bloom，不加屏幕镜头光斑。生活舱灯从偏暖改为中性偏冷，记录匣工位以定向主光与弱补光替代两个无阴影灯，船内用小范围顶置工作灯补台面。额外阴影以局部 Spot 为限，影和灯按距离淡出；枪械仍用独立视口，HUD 不进世界 Glow。
- **保留。** 日照方向和颜色、曝光、山脊和真空黑位不变；着陆坪同机位的 180 × 90 天空采样块平均 RGB 约从 `(4, 8, 12)` 到 `(4, 7, 11)`，没有抬升。玩法、碰撞、关卡入口与旧训练场／清剿／Benchmark 不变。未启用 SSR、SSIL 或 SDFGI；无外部生成调用、新贴图库或全局渲染设置改动。

首轮尝试一度把近景方向光级联收得更紧；生活舱单项定位时，同一候选由近级联的中位 7.72 ms 恢复到原级联的 6.50 ms，画面收益不值得这项开销，最终完整保留 ML35 的日照级联。[迭代诊断](cascade-diagnostic.log)不是下表的发布性能数据。钻机首轮试灯在平台上方，光路被遮而不明显；最终验证了平台下方光源的真实散射贡献，而非只检查参数非零。

- [84 项任务与物理检查](mission.log)通过（14,952 个物理步），覆盖记录回收、负载货梯、实物冰芯装载、弃货、遮挡和重启。四轮原生探针的 WASD、暂停、恢复、F5 与排气入镜检查均通过。
- [原生连续路线](route.log)：自动输入从自然出生点进入生活舱、取记录匣、乘两段货梯、登船并封舱；3,700 步、生命 100、射击 0。未瞬移玩家或直接推进状态。另核对了常规启动器进入 Metal Forward+。这不是玩家首玩或美术验收。

## 1600 × 900 原生短采样

在同一台机器关闭 VSync、不限帧，按 ML35 → ML36 → ML36 → ML35 的顺序运行；四个机位每轮各取 288 帧，两次同角度脚本摆动。钻机探针正看有效排气与运行中的轨道巡检，记录匣探针包含新主灯。表内为两轮各自统计量的最小～最大值，单位 ms；不是单独的 GPU 时间。

| 机位 | ML35 中位 | ML36 中位 | ML35 P95 | ML36 P95 |
| --- | ---: | ---: | ---: | ---: |
| 着陆坪／撤离船 | 5.57–5.88 | 5.78–5.90 | 8.08–9.22 | 7.05–8.18 |
| 钻机／排气和活动巡检 | 7.21 | 6.83–7.02 | 8.46–8.47 | 7.60–8.16 |
| 记录匣工位 | 6.10–6.17 | 5.93–6.00 | 7.52–7.72 | 7.36–7.77 |
| 生活舱玻璃／灯具 | 6.43–6.79 | 6.26–6.33 | 7.97–8.22 | 7.89–7.92 |

原始数据：[ML35 第 1 轮](performance/baseline-1.json)、[ML36 第 1 轮](performance/enhanced-1.json)、[ML36 第 2 轮](performance/enhanced-2.json)、[ML35 第 2 轮](performance/baseline-2.json)。着陆坪分轮对照中位帧时增加 0.02–0.21 ms；实际出雾的钻机机位和生活舱没有复现候选的额外开销。不把短采样波动当作全关提速，也不外推到其他设备或分辨率。

## 复现

```sh
./launch-polar.command
POLAR_LIGHTING=baseline ./launch-polar.command
./tools/validate_polar.sh --lighting
```

`--lighting` 会串行生成新旧截图、分项诊断、成对帧时与当前方案的连续路线。输出默认在 `artifacts/`，或用新的 `POLAR_QA_OUTPUT` 目录。完整冻结的 ML35 数据仍在旧报告及提交 `d7972d6`，不和本轮改进过的采样方法混用。

**视觉边界：** 亮点更集中，近景接触比远景变化明显，排气只在钻台下可读；没有改变场景整体色调。材质和建模仍是程序化基线，本轮不宣称达到照片级，用户视觉验收待定。
