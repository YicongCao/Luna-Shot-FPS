# ML31 · T-Bug 支撑脚与转弯

[同步原生侧拍](review.html) · [物理测量](metrics.json) · [每张图的实测足底位置](native.json)

默认 ML26 机械虫保留六条腿与原有零件，改为髋、膝、脚垫三个独立刚性组件和伸缩执行器。对建筑层向下取样，锁定支撑脚垫的世界位置与朝向；根据身体实际平移/转向按两组三足换步。双连杆解算不延长骨段；超出可达范围不记为有效支撑。未探到表面则收脚，约10Hz复核已有支点。仅视觉，不驱动胶囊或碰撞。`QUARANTINE_GAIT=baseline` 对照原整腿摆动。无新生成服务或烘焙。

| 相同胶囊路径 | 旧版近地足底水平速度 | 新版 |
|---|---:|---:|
| 平地巡逻 | 0.869 m/s | <0.001 m/s |
| 追逐 | 2.259 m/s | <0.001 m/s |
| 原地转180° | 1.842 m/s | 0.003 m/s |
| 12°上坡 | 0.830 m/s | 0.004 m/s |

指标只包含连续两次距地面不超过35mm的足底样本，不等于地面反力。坡道胶囊真实上升0.350m；脚垫声明支撑期的最大漂移低于0.003mm；膝/踝连接点最大间隙小于0.002mm。转弯和上坡某些瞬间只有两个可达支点，不是静力平衡或动力学模拟。不保证运动平台、碎石或楼梯。未修改寻路、速度、伤害、生命、死亡或材质。

首次移除地板后旧支点未失效，失败日志保留在 before-floor-refresh。修正后83项脚本化60Hz物理与关节检查、40项原生捕获检查通过。18张原生图是同镜头的非自主侧走序列；逆光下暗脚垫和远侧腿互相遮挡，不能仅靠单帧判断毫米级位移。

真实启动器与任务回归通过：49任务、69训练、24反馈、12演示、20重播/实玩衔接。Benchmark编排会冻结敌人，不能用其帧率证明步态开销。因此另测60秒实际移动、8虫起始的路线（Apple M6 / Metal Forward+ / 1920×810，VSync请求关闭）。旧/新分别走过11个路点，累计活虫移动462.9/464.3m；平均59.97/59.97 FPS，P95 17.605/18.159ms，P99 18.317/19.124ms。末帧绘制调用1942/2440；拆分关节有成本，本机窗口条件不能推出零开销。历史7个Texture RID退出警告仍在。

复现：`Godot --headless --fixed-fps 60 --path . --script tools/quarantine/test_bug_gait.gd`，原生方式见脚本文件头。GAIT_OUTPUT可指定输出，默认recheck目录。两种步态的胶囊路径相同，不宣称为无人通关或整体3A验收。
