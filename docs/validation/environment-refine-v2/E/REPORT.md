# ML15 E 信号塔

技术通过；实施视觉复查通过；用户实机验收待定。原生Godot4.7.2/macOS。

静态低模10336三角，高模39392三角，4组高低模/cage；4K制作、2K运行。保持2×2m底座、最大3.8m天线和14.2m总高。开放X桁架、四柱/连接板、三级天线/抱箍/馈线、线缆夹和底部柜体完成；两个方向的镂空射线采样通过。

警灯为独立旋转亮区，1秒一圈、1Hz短脉冲，Spot随亮区方向照亮天线顶部；不是转动均匀发光圆柱。实际像素、四个相位、方向同步、暂停和包络检查通过。beacon-cycle.mp4为Godot MovieMaker原生5秒周期视频（固定60fps采集，不作性能证据）。没有制作空气中可见的光锥。局部补光受F9、Bloom受F7控制。

首轮性能21.391ms未发布。旧/新无VSync短诊断确认额外提交开销；把重复灯座/同步灯罩合为模块内MultiMesh绘制，保留独立挂点、真实补光和各塔相位。绘制对象由1132降到984，灯数不减少。默认VSync、1600×1000、60秒同路线复测P95 9.835ms（原基线+1.94%）通过。该总览路线的蓝灯/警灯补光激活帧为0，不能代替最终近景灯光路线；近景功能已有独立像素证据，最终还需混合路线验证。

Tripo本件60积分；全五件总300积分，低于400上限，无重抽。静态生成参考与本地精确高低模分别存档，没有把参考GLB冒充受控低模。天空/曝光沿用现有设置；小型螺钉、夹具和灯罩在远景不保证逐个可辨。

最终整合已完成，最新灯光池为最多2个Omni+1个Spot；上文性能与进度按各阶段历史保留。全五件最终状态、完整灯数与近灯60秒性能见 [整场报告](../final/REPORT.md)，用户实机验收仍待确认。
