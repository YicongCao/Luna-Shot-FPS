# ML15 C 检修桥

技术通过；实施视觉复查通过；用户实机验收待定。macOS Godot4.7.2 Compatibility原生。

静态7,520三角、高模27,920三角、3组配对/cage；4K制作烘焙→2K运行。分块防滑板、暗色边梁、独立电缆/夹具、护栏接头、边缘支腿/斜撑、两侧四蓝灯。防滑微纹理在高模材质层烘焙，不增加平面贴花法线补丁。

实际低模射线检查32个步行面点+9个桥下点，通过2.4m步行面、至少3m宽/2.2m高净空；两端无新增横栏。原真实玩家胶囊路线、出生/重置/命中/换弹/暂停检查通过。前后左右原生灰模/PBR、掠射光、3/10/20m和暗区关闭Bloom受光证据在candidate。

C两实例共8条蓝灯，随模块局部挂点旋转，常亮。近景能够照亮侧梁/护栏，实际补光与Emission分开对照通过。远处细小防滑纹理不保证逐条可辨，模块轮廓仍是轻型检修桥，并非大体量建筑。

性能最初21.395ms失败。优化稳定灯槽绑定、近距离渐隐和旧固定蓝灯移除后，60秒P95 10.015ms，原始9.648ms基线+3.80%。1024局部阴影atlas；8个槽最多同时激活2个Omni，红灯8m/蓝灯4.5m，最后1m渐隐。保留真实CubeMap阴影。Dual Paraboloid在Compatibility实测不支持，该次数字明确无效；512atlas未稳定改善，最终恢复1024。

Tripo参考60积分，本轮5项合计300。当前B1/B2/C发布；D/E待完成，不宣称全部环境已验收。旧固定坐标蓝灯已撤下，D随后由模块灯接管；旧E警灯仍临时保留。

最终整合已完成，最新灯光池为最多2个Omni+1个Spot；上文性能与进度按各阶段历史保留。全五件最终状态、完整灯数与近灯60秒性能见 [整场报告](../final/REPORT.md)，用户实机验收仍待确认。
