# B2 侧面旋转散热风扇 — 原生验证

平台：macOS / Godot 4.7.2 / Compatibility。2026-11-16。

## 实现

每座 B2 的局部 +X 侧增加一组竖排三风扇；6 座共 18 个叶轮。七片带厚度的后掠叶片、深色背板、金属护圈/护网、支架、固定件和橙色标识全部由代码构建，无新增贴图、Tripo 或 imagegen 调用。

叶轮分别为 43 / 49 / 46 rpm，采用可辨认叶片运动的展示转速。绕局部轴转动，跟随塔架的 90° 布局旋转；护网与中心盖不转。暂停时停止，恢复后继续；F5 不重新生成组件。护罩采用静态碰撞，叶片不参与动态物理。

保留 B2 原 GLB、材质、散热片及塔架结构。风扇安装于原侧板外侧，背板表示封闭风道入口；没有切开原资产或重做 UV。运行时附件通过既有模块加载脚本挂载，重建关卡不会丢失。`--whitebox` 仍显示原规划白模。
