## 空间与视觉检查

- 外围环路、中央十字通道和两侧维修支路可连续通行。测试路线绕过训练靶，不以传送代替路线内部行走；不同测试路线之间使用放置以隔离检查。
- 两组坡道在上下两个方向通过，顶部高度均为 2.4 m，桥下仍在地面通行；桥侧护栏阻止胶囊走出桥面。
- 四侧围墙在跳跃时仍阻止玩家越界，五个靶均从对应射击位命中，塔芯能挡住射线。
- 原生总览呈现重复塔架、配电阵列和两条检修高架；没有旧飞船、基地或储罐混入。当前以模块读形、尺度和通行验证为主，尚不代表最终环境美术。

## 证据与复测

`generation.json`：20 个种子和一致性/失败保护；`modules.json`：真实场景资源及接口测量；`headless.json` / `native.json`：关卡物理检查；`rifle/`：新关卡内的 LC01 专项与材料对照。

`tools/validate.sh` 检查生成器、模块、枪械基准及关卡；`tools/validate_rifle.sh` 检查 LC01 与场景切换。日志位于忽略的 artifacts 或本证据目录中的 `.log`，JSON 和图片作为持久证据保留。

初次测试发现两段测试路线直接穿过设备阵列；修正为沿预留环路/主通道行走，并将整段路线检测加入生成器校验。最终报告均为修正后结果。

本轮没有调用 Tripo，也没有修改枪械网格/贴图。后续精修预算仍为 A/B/C/D 四个固定主题模块。
