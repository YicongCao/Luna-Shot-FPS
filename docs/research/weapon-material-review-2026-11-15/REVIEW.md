# 枪械美术差距复查与业界流程调研

2026-11-15。依据用户本次提供的概念图与实机截图，对照当前源代码、运行时贴图和官方技术资料。**本轮是研究和验收纠偏，不修改模型、贴图或游戏代码，不调用 Tripo。**

结论：当前有工业附件和微表面实现，但没有达到批准概念的材料层次、精确轮廓和使用痕迹。ML06 的功能测试、UV 不变检查仍有效；“视觉已验收”的结论应撤回。需要修正材质分区、磨损位置、附件造型和烘焙质量，不能靠继续加一张噪声图解决。

## 1. 问题清单

优先级 P0：影响整体材质可信度或管线正确性；P1：明确的概念还原缺项。以下均未视觉验收。

|---|---|---|---|---|

## 2. 本项目查到的原因

以下是源代码/文件事实，和仍需实验的推断分开记录。

### 已确认

- `tools/weapon_pipeline/finalize_materials.py:76–98` 按零件编号分配材质；白壳和橙漆 metalness=0，裸金属=.95。**漆面设为0本身合理，问题是缺少脱漆露底遮罩和独立螺钉分类。**
- `tools/industrial_wear/wear.py` 与 `micro_surface.py` 都没有为做旧修改 ORM 的蓝色金属度通道。因此白壳上的划痕不会自动成为裸金属；橙色涂层也没有因掉漆露出金属的行为。
- 当前 ORM 以原材质分类遮罩统计（全部该类像素，不是仅截图区域；数据在 `material-statistics.json`）：

| 分类 | metalness P5/P50/P95 | roughness P5/P50/P95 |
|---|---|---|
| 白涂层 | 0 / 0 / 0 | .435 / .443 / .490 |
| 橙涂层 | 0 / 0 / 0 | .337 / .357 / .365 |
| 原裸金属区 | .949 / .949 / .949 | .255 / .271 / .282 |

- `scripts/weapon_field_kit.gd` 的屏幕是矩形，排线是平直长方体，紧固件只构造一条驱动槽；这三项不是灯光或分辨率问题。
- `micro_surface.py` 用每面法线的主轴选投影，并以每面几何法线构造切线方向。**没有做三向平滑混合，也不是逐角 MikkTSpace 切线的逐项一致性检查。**这些是潜在接缝/方向跳变来源，不能说已证明就是截图错位的原因。
- 主体 BaseColor、ORM、NormalGL 的 `.import` 中 `mipmaps/generate=false`；材质虽设置了各向异性带 mipmap 的过滤，文件并没有生成 mip 层。需检查斜视稳定性。`compress/normal_map=0` 不应误读为“禁用法线贴图”。
- `scenes/player.tscn` 的枪械 SubViewport 使用 `own_world_3d=true`。`weapon_lighting.gd` 已使用天空反射，`studio_sky.gdshader` 有两个亮反射区域；`lunar_lighting.gd` 同步太阳方向并调节环境强度。因此“再在主场景加一个探针”不保证改善枪械，应单独测试武器视口的反射。

### 需要后续隔离实验

贴纸错位究竟主要来自跨面投射、采样锯齿还是 UV/切线问题；泛白棱线中哪些是反射、哪些是烘焙残差；2K atlas 是否给小螺钉足够像素；油膜被曝光压平的程度。只凭两张不同光照和构图的图不能定量归因。

## 3. 业界怎样实现

### 3.1 先建立材质，再按层做旧

在金属度/粗糙度工作流里，漆、锈和污垢通常属于非金属表层；掉漆露出的裸金属才恢复导体反射。不能把整把枪 metalness 拉满来获得“金属感”。[Adobe PBR Guide Part 2](https://www.adobe.com/learn/substance-3d-designer/web/the-pbr-guide-part-2)

对应本项目建议的层顺序：底层钢/铝 → 底漆 → 白/橙/深色表面涂层 → 局部剥落露底 → 不同尺度擦痕/凹坑 → 油膜、指印、积尘及局部氧化。每层用相关联的遮罩控制颜色、粗糙度、金属度和高度；不是每层都改所有通道，也不让一张灰度图机械控制所有通道。

橙色弹夹应保留大面积完整漆，同时在边缘及装卸接触带显露基底；油膜需要较大尺度、低粗糙度的拖擦斑，干污/尘则偏粗糙，凹坑和划痕另有中小尺度。这里的具体层组合是本项目建议，而非统一的业界参数配方。油污不能全做成黑色，锈蚀也不能只是橙色漆斑；铜氧化与钢锈应区别处理。

Marmoset 的武器制作案例先烘焙辅助图，再叠底材、涂层和磨损，并反复修改粗糙度、手绘修正遮罩，在渲染器中逐轮比较。它展示的是可借鉴流程，不代表所有工作室采用同一软件。[Ben Armstrong：硬表面武器流程](https://marmoset.co/posts/baking-a-hard-surface-weapon-in-toolbag/)

### 3.2 磨损要理解部位和接触关系

Adobe 的 Metal Edge Wear 生成器使用位置、曲率、AO、世界法线，并支持微高度/微法线作为输入；这说明它不是“给全模型撒随机划痕”。[Metal Edge Wear 官方文档](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/effects/generators/metal-edge-wear)

项目落地：凸边形成断续涂层损失；手掌接触区发生擦亮和油脂覆盖；凹槽和夹具下积污；换弹接触区出现方向一致但长短不一的刮擦。曲率生成器只给初稿，必须手绘/人工区域掩码打破均匀性。不要让所有边缘同时发白，也不要让一块不经常碰触的顶面和弹夹接触面一样旧。

Respawn 在《Apex Legends》武器访谈中介绍：先看正交图和第一人称构图，完成高模及展开后的第一人称模型；不同材质使用不同划痕，再组合生成器和手绘做标记、磨损及螺钉。对我们最有价值的是材质差异和第一人称尺度的验收，而非只增加微噪声。[Adobe / Respawn 一手访谈](https://www.adobe.com/products/substance3d/magazine/apex-legends-texturing-battle-royale-phenomenon-2019.html)

### 3.3 金属需要可读的反射形状

窄倒角、平面变化、粗糙与光滑斑之间的区别，要靠合适的反射和斜向主光显示。Marmoset 的硬表面照明案例会调整反射形状、主光角度和天空光来读取表面缺陷，而不是仅增加灯亮度。[硬表面照明案例](https://marmoset.co/posts/how-to-light-hard-surface-assets-in-toolbag/)

本项目应建立固定曝光的中性材料台：同一照明下同时摆裸钢、铜、涂漆、橡胶样块；先关闭 Bloom/flare 检查材质，再回到关卡。当前武器视口已有天空反射，建议检查反射带的宽窄、方向及背景对比，不能直接移植其他渲染器的灯光参数。Godot 的探针/天空反射机制见[官方说明](https://docs.godotengine.org/en/stable/tutorials/3d/global_illumination/reflection_probes.html)；具体特性需以本机 4.7.2 Compatibility 验证，不借此承诺更换渲染管线。

### 3.4 精确锋利低模：先精确造型，再合理分配几何

锋利不是零宽度刀口。可读的硬表面通常需要平整面、准确截面和有控制的窄倒角；重要剪影要保留在低模。加权法线只能改变高光，不能把歪斜或融化的轮廓修成规整机械件。

本项目建议：屏框按二维正视轮廓挤出，管线用曲线扫掠，十字螺钉做可复用高低模，机匣大平面和轮廓用受控拓扑重新整理；高模倒角供烘焙，低模保留第一人称看得见的倒角/截面段数。布尔在独立闭合零件上完成，避免在已合并多层壳体上无差别操作。规则轮廓无需再依赖生成模型猜测。

### 3.5 烘焙仍是有效路线，需修正输入和契约

Marmoset 的烘焙指导强调投射笼、偏斜修正、匹配烘焙组，以及烘焙与渲染切线空间的一致性。常规切线法线管线里，硬边通常也需要 UV 切缝；反过来，UV 切缝并非都必须硬边。烘焙前固定三角化，避免导出时切分变化。[Toolbag 烘焙指南](https://marmoset.co/posts/toolbag-baking-tutorial/)

项目检查顺序：

1. 用纯灰和关闭法线贴图确定错误来自几何还是贴图。
2. 固定最终低模的三角化、逐角法线、UV，核对导入后切线及法线约定。
3. 分件配对烘焙，检查 cage 不穿入邻件；十字槽、文字、警示条检查投射偏斜。
4. 导出 Normal、AO、Curvature、Position、World Normal、Material ID。前两张用于运行时，其他主要辅助制作，不必全部装进游戏。
5. 按第一人称投影尺寸分配 texel density；比较现有2K、局部独立图或4K试样，不能默认升分辨率就解决问题。
6. 核对 BaseColor 的颜色空间、ORM 的线性数据、OpenGL 法线方向、padding、mipmap 与过滤。Godot 默认材质文档明确其法线约定；导入文档说明纹理采样配置。[Godot 材质](https://docs.godotengine.org/en/stable/tutorials/3d/standard_material_3d.html)、[纹理导入](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_images.html)
7. 单独检查微法线合成与 UV 缝，不能以 RNM 公式存在或“有像素变化”代替正确性验证。

**保 UV 策略：**保留未改部件 atlas；新增屏框、管线、螺钉各自使用受控 UV。若原机匣拓扑/UV 是质量瓶颈，需要单独提出局部重拓扑与贴图转移，不应为了保持一个哈希而继续锁死错误网格。此前“保 UV”要求仍有效，本轮只是指出它与需要重拓扑的区域之间的取舍，尚未实施重排。

### 3.6 imagegen 的有效边界

仍适合提供污迹、油痕、微凹坑和划痕的图案素材；应拆为不同尺度和不同材质的输入，再结合部位遮罩，最后生成配套通道。生成的灰度明暗不能直接证明是可信高度、已去光照、可平铺或具有准确物理尺度。

它不能替代：六边形屏框、弯曲管线、螺钉十字槽的准确几何、Material ID、烘焙 cage、切线同步或字体识别。没有必要再用整枪生成来解决这些明确、规则的小零件。已购买工具不是本结论的前提；本地 Blender/程序化流程也可落实这些原则。

## 4. 建议下一轮顺序与交付门槛

先做三个小样，不立即全枪重做：

1. **橙色弹夹材质样板**：正确裸金属/漆层、少量中尺度凹痕、油膜、积污、磨损；同光照前后、旋转掠射光、关卡距离都通过。
2. **一个金属十字紧固件**：真实沉孔、十字槽和独立材质；再替换全枪对应紧固点。确认是螺钉而非不带槽的铆钉，避免两者混用。
3. **一个轮廓样板**：六边形屏框 + 一段弯曲铜管；先看无材质剪影，确认轮廓再做高低模和贴图。

之后再解决侧面字标、警示贴纸、全枪边缘掉漆和UV/烘焙残差。验收提供固定第一人称机位、正侧视、三种光照、底色/金属度/粗糙度/法线拆分，以及运行时前后对照。屏幕计数、换弹、红点等功能回归继续保留，但不作为美术通过的替代品。

本轮没有修复上述问题；它们作为返修清单保持打开。
