# 从 ChatGPT 讨论提炼 Luna-Shot-FPS 可用结论

2026-11-15。来源：[移除光效贴图效果](https://chatgpt.com/c/6af6f8d6-12ec-83ea-a85f-a03800816bf3)。通过会话读取工具取得三轮文字记录，分页已结束；部分图像内容未随消息正文返回，本文不将未检查的生成图当作证据。

这段讨论属于技术建议和主观推断，不是资产制作实验报告。下面区分原讨论结论、技术修正和本项目建议；本次只整理研究，不推进模型精修。

## 可直接采用的结论

### 1. 区分概念图、资产和实机

原讨论最后明确承认：用于展示“白模能做到的程度”的图片，其实仍是 ImageGen 生成的二维画面，没有真实导入引擎渲染。因此它不能证明白模加材质就能达到那种效果。

本项目采用三种明确标签：概念参考、离线资产预览、引擎实机。只用第三种证明游戏表现；离线预览帮助检查几何和材质，不能替代实机验收。当前 LC01 幻想图仍只是目标，不能与训练场白模混称为已完成的画质。

### 2. 把视觉差距拆到几何、表面与光照

应先处理轮廓、比例、主要开口和分件，再处理表面细节。以枪械为例：枪托开口、护圈、瞄具孔、线圈之间的间隙必须在可转动的三维资产中成立；不能用一张漂亮的侧面图代替。

普通法线贴图改变着色法线，不改变几何，因此无法补出缺失的真实轮廓。Godot 官方文档明确区分这一点，并要求 OpenGL 风格法线。[Godot 材质文档：Normal map](https://docs.godotengine.org/en/stable/tutorials/3d/standard_material_3d.html#normal-map)

但原讨论“真正的瓶颈是几何，而不是贴图”不能作为永久定律。当前积木代理最先暴露几何差距；几何合格后，材质、反射、曝光和构图仍可能成为主导问题。每次只针对实际失败的一层修改。

### 3. 枪械走完整资产链，按阶段留下证据

本项目建议流程：

**分件白模 → 轮廓冻结 → 高模 → 低模/UV → 烘焙 → 干净 PBR → 少量磨损/标识 → 实机对照。**

每一步交付独立可检查文件；下一步不能掩盖上一步的错误。高模、低模、UV、烘焙都完成之前，不声称“只是再调一下灯光就能接近概念图”。

这条完整高低模流程适用于首个近景枪械样板，不应推导成“每一块远景地板都必须单独做高模”。环境模块后续可以选择共享材质、平铺纹理、通用条带纹理和重复零件；具体方法另做样板验证。

### 4. ImageGen 的角色是设计与二维辅助

可用来探索外形、配色、标识、磨损分布和材质参考。经过清理、投射及验证后，部分二维图像可以成为贴图制作的输入。

不能默认它已经提供一致三视图、正确 UV、可用拓扑、可信法线或相互匹配的 PBR 数据。尤其不能把一张带阴影/反光的外观图直接当成干净 BaseColor，再把它转灰后当 Roughness 或 Metallic。

材质应分层验证：先白色涂层、深色骨架、橡胶和能源带四类材质，再加编号与有限磨损。金属度和粗糙度具有独立含义；发光材质也不等于已经照亮周围环境。[Godot 材质参数](https://docs.godotengine.org/en/stable/tutorials/3d/standard_material_3d.html)

### 5. 最值得建设的是可重复的制作与验收工具

原讨论建议自动材质化、自动细节增强、自动渲染。针对这次失败经验，建议优先顺序改为：

1. **资产约定与检查**：分件编号、单位、坐标、pivot、挂点、拓扑、UV、材质槽和纹理通道。
2. **稳定导出与回导**：同一个源文件生成 GLB，导入后检查部件、位置、包络和材质链接。
3. **固定实机验收**：固定相机、FOV、分辨率、光照、姿态；记录改动前后与多视角证据。
4. **一件资产的可复现烘焙**：同名高低模、cage、法线、AO、接缝检查、失败可定位。
5. **再扩展可复用材质和规则化细节**：在合格几何上批量应用，而非自动给所有白模加噪声。

脚本能够检查数据一致性、曝光是否截断、贴图是否缺失等客观项目，但“画质达到概念图”仍需图像审查和人的判断。通过技术测试不等于通过美术验收。

## 不应照搬的说法

| 原讨论内容 | 本项目处理 |
|---|---|
| 55–65%、30–45%，后来又修订为 85–95%、50–65%、35–50% | 没有统一量表、实际模型、同机位渲染或评审实验，不引用这些比例制定承诺 |
| 生成一张“能力范围内效果图” | 仍可能由图像模型补出尚不存在的几何，不作为生产能力证明 |
| 完整 UE5 技术清单 | 是候选工具罗列，不是已验证依赖；不据此迁移引擎或一次性加入所有效果 |
| 先做自动材质化和自动细节增强 | 当前先建立分件、回导、烘焙与验收；等首件通过再扩张自动化 |
| 白模加 AI 材质可以有商业游戏观感 | 取决于风格、镜头、资源和质量控制，没有实测就只能作为可能性 |
| 每个资产必须相同的高低模流程 | 近景英雄资产与重复环境模块分别选方案；本轮完整验证枪械 |

月面照明可保留黑天空、方向明确的太阳光和克制的人工照明方向；不因科幻题材自动加入浓雾、满屏辉光或强蓝色环境光。光照策略先服务当前资产的读形，再验证所需引擎功能。

## 对 LC01 的具体影响

现有 [零部件 spec](../art/rifle-v1/SPEC.md) 已记录大部分阶段要求。当前具备分件 Godot 代理、Blender 源、GLB 和 22 项回导检查；[回导结果](../validation/whitebox-v1/weapon-roundtrip.json)只证明这批白模的名称、位置和包络对应，不证明已有完整美术生产管线。

下一步建议：

1. **先完成 B1 轮廓比较**：评估横长能源匣、枪托开口、前护罩露出三环的方式、瞄具厚度；处理幻想图与现有代理的不一致。保留握持与瞄准轴约束。
2. **从一组相邻部件做闭环样板**：建议机匣侧壳和其相邻深色骨架。它们同时涉及曲面/斜面转折、倒角、接缝、遮挡、涂层与金属区分；比先做整把枪更容易定位失败。
3. **同一模型保留三种检查画面**：纯灰材质检查形体；UV checker/法线预览检查资产；简单干净 PBR 检查光照响应。三种都进入 Godot，再考虑磨损和青色发光。
4. **单组通过后再展开整枪**；环境继续保持白模。不把环境材质化、复杂光照、机器人制作和枪械精修同时启动。

这是基于讨论和当前工程的下一阶段建议，本次未执行 B1 或高模制作。图像模型和三维生成工具可辅助某一步，但不能自行跳过该步的验收。
