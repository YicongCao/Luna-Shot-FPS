# ML15 环境建模管线事实核查与改进建议

2026-11-16。范围：当前B1/B2/C/D/E的ML15流程，另对ML06枪械的imagegen微表面作区分。本次为源码、任务记录、GLB网格计数和已有图片核查，没有重新建模、付费调用或运行游戏回归。当前默认资产不变。

## 结论

高模和低模都是本地Blender脚本重新生成的；Tripo高密度网格没有进入最终高低模配对或烘焙。实际流程存在两条分支：imagegen概念→Tripo高密度参考并归档；规格/概念解释→本地参数化高低模→真实投射烘焙→打包→Godot。

“用了Tripo、做了高低模烘焙”都属实，但不等于“把Tripo的细节烘到了低模”。本地高模本身遗漏的装配设计，不会在烘焙时自动恢复。此次核查不能量化Tripo作为人工视觉参考的贡献；可以确定最终构建脚本没有导入、重拓扑或投射Tripo网格的步骤。

## 高模细节具体如何制作

源码tools/environment_refine/build.py从空场景开始，用box/cylinder/Bezier curve生成结构。HIGH=True和False各执行一次同一配方；高模倒角3段、低模1段，圆柱24/12边，曲线分辨率8/4。高模螺钉额外Boolean切真实凹槽。框架、鳍片、弯管、面板和固定夹由尺寸/位置/重复规则控制。它不是手工雕刻完成的高模，也不是从Tripo网格直接简化得到的两套模型。

材质源码materials.py使用Object坐标Noise：大尺度4、中尺度60、微尺度480。边缘掉漆由单件包围盒边缘距离与噪声阈值组合；油污/灰尘主要是大尺度噪声阈值。微凹坑用Bump，Distance参数0.0003m、Strength 0.23，不是真实0.3mm网格凹坑；踏板防滑纹由数学波形驱动Bump。当前这五件材质未读取imagegen纹理。Position/WorldNormal/Curvature等虽导出，但没有形成完整的语义化磨损绘制流程；主要做旧仍靠通用噪声与边缘距离。

bake.py确实执行Cycles selected-to-active、显式cage、4K法线/AO及通道烘焙。每组高低模隔离防止串投射，再统一atlas；低模固定三角化和逐角法线，Smart UV Project自动展开。pack.py缩至2K，归一化法线，R/G/B打包AO/Roughness/Metallic。烘焙目标是低模UV，不是将“高模UV”搬给低模。

## imagegen与Tripo的实际职责

ML15的imagegen为1张场景板和5张资产概念图，共6次；不是五套高模贴图。ML06枪械曾用imagegen灰度素材，经去低频、边界处理、导数和RNM合成微法线；这是另一路流程，且仍不是几何高模。来源：tools/industrial_wear/micro_surface.py。

## 为什么重建，以及哪里做错了

当时选择“Tripo形体参考+Blender精确制作”是为了控制尺寸、平面、镂空、连续坡面、灯具挂点、动态风扇接口、低模预算和可复现性。重建问题部件有必要，但这不证明所有生成部件都必须丢弃。当前脚本整件重建，缺少逐件“可保留/需修复/需替换”评估和几何来源清单。

概念和Tripo预览中的管路接头环、底脚安装块、层框端部连接、底柜面板层次，在本地版有不同程度的简化。当前版保住六层、开放结构和功能接口，但“某类零件存在”代替了“零件形态及装配关系吻合”的检查。程序化配方没有描述的细节，分辨率再高也不会出现。这与ML11枪械复盘是同一种风险。

“先做高模再做低模”的代码执行顺序不等于完成了高模美术评审。同一个中模/配方生成高低两套是合法方法；问题是设计不足时就一起生成、烘焙并推广。相应地，高模面数、cage、UV、通行、性能等检查通过，不能证明实现了概念效果。

## 建议的改进流程（未实施）

1. **先在既有B1上做保形试验，不新增付费任务。** 导入归档Tripo高密度GLB，按零件检查正背面、镂空、平面、厚度、比例和局部缺陷；逐件记录保留、修复或重建理由。用当前模型与候选做相同相机灰模对照。不能仅凭灰色预览宣称生成网格可直接生产。
2. **高模采用混合来源。** 合格的Tripo细节直接保留为高模源，问题面局部重建；规则框架、鳍片、法兰和螺钉用程序化组件补齐。每一组记录实际来源对象，避免付费候选仅归档、最终又从空白猜设计。简单规则件也可不调用Tripo，先明确每次生成要解决什么难题。
3. **先验高模的形与装配，再验低模。** 固定轮廓、部件比例、缝隙、接头、底脚、黑白色块。低模根据已认可高模做局部重拓扑/受控减面，复杂轮廓和透空保留几何，表面小槽/划痕交给法线。禁止对全模型一次性无差别减面；共用基础网格生成高低模仍可使用，前提是已经通过设计检查。
4. **UV与烘焙服务实际视距。** 主观察面有意识地分配像素密度、接缝与硬边；按结构分组调cage，检查偏斜和投射遗漏，保持导出三角/法线一致。对鳍片等重复结构可试验复用纹理与共享细节，但必须在实际Godot视距验证。保留现有Cycles工具，不把换软件当作自动提质方案。[Marmoset高低模/cage指南](https://marmoset.co/posts/toolbag-baking-tutorial/)
5. **增加有位置和使用逻辑的材质绘制。** 油污围绕接口，擦痕沿检修/装卸方向，灰尘积于缝和遮挡处，露底同步改变底色/金属度/粗糙度，并保留干净区域。自动生成器做底层，逐件局部修正做最终设计。可借鉴Substance层/遮罩/Anchor的关联思路，也可在Blender与现有脚本实现；当前项目没有完成这一层的工具集成。[Adobe Anchor说明](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/effects/anchor-point)
6. **imagegen只补适合它的图案。** 可制作油迹/磨损参考或遮罩，去除明显光照、校准尺度后局部使用。机械接头、面板分层和底脚轮廓必须靠几何。不要把生成图直接视为物理高度、正确法线或自动对齐的UV/PBR整套图。
7. **材质与场景光照分开验收。** 中性光看涂层/金属区别，掠射光看表面，实际关卡看远近尺度；关闭Bloom检查结构，再恢复。把概念中的视觉特征列成图像对照项，缺少一项就保持开放，不能仅凭技术检查进入下一个模块。

建议先证明一个B1能从现状改进，而不是再批量重做五件。目标是获得可验证的轮廓、装配、材质与灯光对应关系；单张生成概念包含未定义或矛盾的背面/尺度信息，不能承诺自动或逐像素一致。默认资源及用户选定的ML06枪械均保持。
