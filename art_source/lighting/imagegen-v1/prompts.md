# Imagegen 光学素材

1. Transparent game VFX texture: a single centered horizontal anamorphic lens flare streak, wide 3:1 canvas. Neutral white luminous core, thin long symmetrical rays, subtle faint parallel diffraction strands, soft alpha falloff, fully transparent empty background and edges. Monochrome neutral white so runtime can tint warm sunlight or cyan energy. No star field, no scene, no text, no logo, no black rectangle, no border. Designed for additive compositing in a hard sci-fi FPS, cinematic but precise, not a thick painted line.

2. Transparent game VFX texture: a single centered round optical ghost/halo. Neutral white soft luminous central core and a delicate broad airy diffraction ring, subtle photographic optical imperfections, smooth alpha falloff to fully transparent margins. Square canvas, isolated, monochrome white for runtime tinting. No horizontal streak, no environment, no star field, no text, no logo, no black rectangle. Designed for additive lens flare compositing in a hard sci-fi FPS.

用途：只提供镜头光学纹理；亮源位置、强度、遮挡与开镜衰减由运行时代码决定。原图完整保留。
